# Generated Ω-ANIME-ANIMATIC-T R2 artifacts

The permanent `Omega Anime Animatic R2` GitHub Actions workflow compiles and uploads the complete **Le Huitième Feu** bundle for Python 3.10 and 3.12.

Each Actions artifact contains:

- `eighth-fire-animatic.html` — self-contained Canvas/WebAudio player;
- `storyboard-contact-sheet.svg` — 30-shot contact sheet;
- `timeline.json` — 5 scenes, 30 contiguous shots, 180 seconds;
- `subtitles.fr.vtt`;
- `edit-decision-list.csv`;
- `audio-cues.jsonl`;
- `manifest.json` with SHA-256 evidence;
- `report.md` with OAK boundaries.

Generated binaries and bundles are deliberately kept in GitHub Actions artifacts instead of being mixed with source commits. Public release, canon promotion and merge remain human decisions.
