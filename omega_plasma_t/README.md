# Ω-PLASMA-T∞

OAK-safe multi-regime plasma compiler: typed state, characteristic scales, explainable labels, model selection, chemistry, topology, HGFM, atlases and unbounded-by-design finite campaigns.

```bash
omega-plasma assess examples/omega_plasma_state.json --output-dir generated/plasma
omega-plasma atlas tearing
omega-plasma campaign examples/omega_plasma_campaign.json --output generated/plasma/campaign.jsonl
```

The package is simulation-first. It grants no authority for high voltage, vacuum, radiation, fusion, propulsion, medical use or hardware control.
