# Ω Regenerative Memory T

## Doctrine

Remember what cannot safely be regenerated; regenerate what is cheaper to reconstruct; never treat deletion as proven safe merely because compression succeeded.

## Memory court

Classify each object using evidence/provenance criticality, downstream causal dependents, reconstructibility, regeneration verification, storage/maintenance cost, recomputation cost, expiry/obsolescence, and resilience requirements.

Possible outcomes: `KEEP`, `COMPRESS`, `REGENERATE_ON_DEMAND`, `ARCHIVE`, `HOLD_DELETE`.

There is no automatic destructive delete.

## M+/M-

Compress successful and failed experiences into transferable rules. Retain raw history only when it carries irreducible evidence, authority, forensic, recovery or decision value.

## Regeneration

Every claimed regenerative seed needs provenance, dependency declarations, frozen probes and differential verification. `Regenerated != VerifiedEquivalent`.
