# PR Fractal Generation

Use this skill when a pull request should be expanded through Ω-PR-5K2N-T∞ while preserving reuse-first, OAK, CVCD and bounded physical execution.

## Core law

```text
C_n = 5000 * 2^n
```

`C_n` is a logical candidate population. It is never interpreted as a requirement to create that many files, lines, commits, agents, API calls or patches.

## Procedure

1. Resolve the exact target PR, repository and head SHA.
2. Load or compile the cumulative GitHub memory and PR Genome.
3. Search historical PRs, modules, symbols, Capability contracts and M− before creating anything new.
4. Compute the exact logical cardinality for the requested generation without enumerating the population.
5. Compile a bounded deterministic sample of virtual AddAtoms.
6. Preserve Explorer and Prosecutor alternatives for construction and falsification.
7. Deduplicate sampled patterns with CVCD-style signatures.
8. Rank only as planning evidence; proxy GO gradient is not measured value.
9. Prefer REUSE → COMPOSE → EXTEND → CREATE residual.
10. Inspect source/tests and benchmark survivors before any physical patch is proposed.
11. Keep selected additions as SPEC_ONLY until a separately authorized patch compiler validates them.
12. If a surviving physical patch set becomes large, split it into dependency-aware stacked child PRs rather than one giant diff.
13. Feed measured outcomes back into M+, M− or M? so later generations learn from evidence.

## Adaptive depth

There is no fixed architectural `N_max`.

A finite execution uses explicit runtime, review and compute budgets. Continue to `n+1` only when the bounded evidence still justifies another generation. A stopped run may resume later from its recorded `next_generation_candidate`.

```text
no fixed architectural N_max != infinite physical compute
```

## Hard boundaries

```text
5K*2^n logical candidates != 5K*2^n files or lines
logical addressability != execution
generated candidate != useful change
proxy score != measured engineering value
sample support != population frequency
reuse similarity != implementation compatibility
compiled addition spec != tested patch
many additions != progress
CI green != external truth
```

## Authority

Default authority is read + draft. Never infer commit, merge, auto-merge, publication, deployment, force-push, permission widening or irreversible authority from generation scale. Repository writes remain separately authorized and reviewable.
