# Ω-AIT-LLMT-ALLT-META-MORPHOGENESIS-T∞Ω

Treat agents as optional compiled structures, not as the primitive of intelligence.

## Doctrine

`Agent != Primitive`
`Capability != Authority`
`Automation != Permission`
`Simulation != Reality`
`Generated != Verified`
`MetaDepth <= VerifiedGain`
`Learning != PermanentAccumulation`

Useful intelligence is the ability to generate the minimum sufficient cognitive structure that transforms a residual into a verified capability, then distill and regenerate that capability with less persistent complexity.

## Workflow

`OBSERVE → RESIDUALIZE → QUESTION → REPRESENT → GENERATE → COMPOSE → EXECUTE → VERIFY → COUNTERFACTUALIZE → SELECT → DISTILL → PRUNE → REGENERATE → META-VERIFY`

The loop is a candidate architecture, not sacred. A Meta-Loop Tournament may replace or specialize it only with verified out-of-sample gain.

## Required competing architectures

Always keep explicit where meaningful: `NO_ACTION`, `GO_MIN`, `AIT`, `LLMT`, `ALLT`, deterministic program/solver, simulation, and hybrid composition. Do not inflate to a higher topology merely because it is available.

## Required objects

Use or define as needed: `MissionIR`, `ResidualField`, `CapabilityGenome`, `IntelligenceGenome`, `SolverGenome`, `GeneratorGenome`, `QuestionGenome`, `ObjectiveGenome`, `EvidenceGenome`, `RepresentationTournament`, `VerifierEcology`, `VerifierOfVerifiers`, `ProofCarryingResult`, `MutationReceipt`, `ArchitectureReceipt`, `RegenerationReceipt`, `MemoryView`, `AuthorityLease`, `IntelligenceIR`, ISA/VM, and `BOOK0` minimal regenerative seed.

## OAK invariants

Truth, safety, authority/permissions, provenance, independent verification, rollback, and observability are non-compensatory. A failed hard gate cannot be offset by higher capability, novelty, speed, revenue, popularity, or model confidence.

`NoZeroTouchWithoutObservability`: do not promote strongly autonomous execution where meaningful failures cannot be detected.

## Meta-generation

Generated solvers, representations, verifiers, loops, objectives, or primitives remain candidates.

For persistent mutation require:

`BASELINE → CANDIDATE → SHADOW → ATTACK → VERIFY → ABLATE → REVIEW → PROMOTE/REJECT → RECEIPT`

A generator must not be its own judge. Auto-promotion is forbidden.

## Regeneration

Target ladder: R0 response/result repair; R1 AIT repair; R2 LLMT regeneration; R3 ALLT regeneration; R4 morphogenesis-policy regeneration; R5 ecosystem reconstruction from BOOK0. Do not claim R5 self-hosting until replay, diff, probes, invariants, and independent verification demonstrate it.

## Complexity autophagy

Every persistent component pays `ComplexityRent = maintenance + dependencies + security surface + coordination burden`. Prefer distillation, merge, hibernation, deletion, or deautomation when verified capability is preserved.
