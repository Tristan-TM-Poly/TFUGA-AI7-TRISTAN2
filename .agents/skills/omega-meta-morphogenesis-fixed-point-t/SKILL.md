# Ω-META-MORPHOGENESIS-FIXED-POINT-T∞Ω

Use this skill when a request asks to generalize, automate, regenerate, compress, fuse, evolve, or operationalize one or more Tristan theories or systems.

## Objective

Maximize verified capability, information gain, transfer, regenerability, optionality, and future-work elimination while minimizing persistent complexity, risk, human friction, epistemic debt, and authority debt.

Do not maximize idea count, agent count, repository count, meta-depth, automation level, or conceptual novelty for their own sake.

## Kernel

Treat the candidate fixed-point kernel as:

```text
OBSERVE
-> RESIDUALIZE
-> QUESTION
-> REPRESENT
-> GENERATE
-> CONTRAST
-> PROBE
-> VERIFY
-> GOVERN
-> SELECT
-> ACT?          # only when separately authorized
-> MEASURE
-> DISTILL
-> PRUNE
-> REGENERATE
```

`ACT` is optional. Capability never implies authority.

## Procedure

1. Identify the concrete residual or decision to improve.
2. Search for an existing kernel, skill, representation, test, or capability before adding structure.
3. Express the task as a `ProofCarryingTransformation` whenever persistent state may change.
4. Generate at least these competitors when material: candidate change, GO_MIN, and DO_NOTHING.
5. Keep Generator, Verifier, Reality Anchor, Authority, and Executor distinct whenever possible.
6. Assign epistemic status. Never silently convert generated/simulated/derived material into observed, replicated, or causal evidence.
7. Assign explicit authority. Tool availability and technical capability are not permissions.
8. Prefer minimal discriminating experiments over broad speculative expansion.
9. Rank residuals by expected verified information/capability gain, downstream leverage, cost, risk, and complexity.
10. Convert reusable results into `CapabilityCrystal` objects: contract, inputs, outputs, generator, evidence, tests, dependencies, provenance, version.
11. Charge every persistent object complexity rent. Compress, merge, archive, or remove objects whose verified marginal utility does not justify persistence.
12. Create a new META level only when the current kernel cannot express the needed behavior and verified out-of-sample gain exceeds meta-complexity cost.
13. Track dependency blast radius for claims, models, code, publications, simulations, products, and decisions.
14. Distill the smallest regenerative core (`BOOK0_MIN`) and test reconstruction closure.
15. Emit an Evolution/Transformation Receipt with before/after identity, evidence, tests, permissions, risk, rollback/compensation, and unresolved residuals.

## Epistemic type guard

Minimum vocabulary:

```text
GENERATED
SPECULATIVE
HYPOTHESIS
DERIVED
SIMULATED
OBSERVED
REPLICATED
CAUSALLY_SUPPORTED
FALSIFIED
```

Hard examples:

```text
SIMULATED  != OBSERVED
CORRELATED != CAUSAL
GENERATED  != VERIFIED
NONDETECTION != ABSENCE
LOCAL_PASS != GLOBAL_PASS
```

If the desired claim exceeds the supporting evidence class, fail closed or downgrade the claim.

## Authority guard

Model authority as explicit allowed actions, for example:

```text
read
search
model
simulate
propose
draft
test
execute
write
publish
spend
govern
```

Never infer higher authority from competence, automation level, popularity, capital, or prior success.

## Meta-stop / apoptosis

Create `META^(n+1)` only if both are true:

```text
not expressible_by_current_kernel
verified_out_of_sample_gain > meta_complexity_cost
```

Otherwise collapse, compress, or reuse the current layer.

A persistent object must pay complexity rent. If it does not, prefer in order:

```text
COMPRESS -> MERGE -> ARCHIVE -> DELETE
```

Deletion requires sufficient provenance/regeneration confidence for anything that may later be needed.

## OAK invariants

- Generated != Verified.
- Simulation != Reality.
- Prediction != Authority.
- Capability != Permission.
- Generator != Judge.
- Automation != Legitimacy.
- Growth != Progress.
- More META != More Intelligence.
- LocalPASS != GlobalPASS.
- PersistentComplexity <= VerifiedNecessaryComplexity.

## Output contract

Prefer outputs that contain:

1. residual addressed;
2. minimal architecture;
3. candidate/GO_MIN/DO_NOTHING comparison;
4. epistemic status and evidence gaps;
5. authority envelope;
6. tests/falsifiers;
7. capability crystal(s);
8. complexity/apoptosis decision;
9. regeneration recipe;
10. remaining residual frontier.
