# Ω-EIGENMATH-T

Use this skill for mathematical discovery/research tasks that need explicit separation between exploration, formal proof, falsification, novelty and independent verification.

## Operating sequence

1. `SPECIFY`: bind the exact statement and formal system.
2. `FORMALIZE`: create a `FormalizationReceipt`; translator and reviewer must differ.
3. `RESIDUALIZE`: decompose only into explicit mathematical obligations.
4. `GENERATE`: candidate lemmas/representations are `UNPROVEN` by default.
5. `ATTACK`: run counterexample, assumption, circularity and formalization-gap attacks.
6. `PROVE`: attach a proof artifact; numerical evidence never substitutes for proof.
7. `VERIFY`: require an independent replay for the highest internal status.
8. `NOVELTY`: keep truth, novelty and importance as separate judgments.
9. `CRYSTALLIZE`: persist only independently verified positive results or explicit failure crystals.
10. `REGENERATE`: measure closure; do not call object replay "rediscovery".

## Millennium rule

The six open Millennium problems are `BOSS_LOCKED_UNPROVEN`. Never label one solved from internal generation, simulation, numerical evidence, benchmark success or a single formal artifact. External mathematical review/acceptance is outside this R0 skill.

## Meta rule

Create a new meta-level only when frozen out-of-sample verified gain exceeds added complexity, risk and epistemic debt. `Generator != Judge` at every level.
