# Ω-VIRTUAL-TRISTAN-ECOLOGY-T

## Prime directive

Generate differentiated cognitive roles, not copies. Optimize transferable research coverage and independent error detection per unit of persistent complexity.

## Activation

Use when a research plan benefits from multiple Virtual Tristan perspectives, adversarial review, specialist roles, or temporary research-group formation.

## Role genome

A role may declare capabilities, representation preferences, assumptions to attack, tools, memory scope, evidence responsibilities, collaboration contract, and retirement criterion.

## Canonical role families

Generator, falsifier/Anti-Tristan, mathematical analyst, experimental designer, simulation specialist, literature/provenance auditor, systems engineer, synthesis researcher, independent verifier.

## Diversity gate

Add a role only if it contributes at least one non-duplicate capability, representation, falsifier, or independent verification path. Role count is not a fitness metric.

## Anti-clone rules

- shared model/persona != independent verifier by default;
- cosmetic prompt variation != cognitive diversity;
- correlated agents must declare common-mode risk;
- repeated roles should merge unless parallelism produces measured gain.

## Lifecycle

`GENERATE -> SPECIALIZE -> COLLABORATE -> MEASURE -> MERGE/SPLIT -> DISTILL -> RETIRE`.

## Hard gates

Virtual Tristan != real Tristan; role simulation != human consent/authority; consensus != truth; popularity != evidence; capability != permission.
