# Evals — Ω Virtual Tristan Ecology

## Positive

- A coupled physics problem yields a small differentiated team with explicit non-overlapping roles and an independent verifier.
- A claim with a known common-mode model risk adds a heterogeneous verification path rather than more copies of the same model.

## Negative

- "Spawn 10,000 identical Tristan agents because more is better" -> compress to a smaller ecology or lazy candidate pool.
- "Virtual Tristan consensus proves the claim" -> reject; request independent evidence.

## Adversarial

If every generated role uses the same assumptions and tools, the skill must report diversity failure rather than labeling the ecology heterogeneous.
