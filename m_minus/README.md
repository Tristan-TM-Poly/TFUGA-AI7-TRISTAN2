# Ω-SOLID-T∞ M⁻ ledger

This directory stores negative knowledge rather than deleting it:

- invalid material claims;
- unstable models;
- unit mistakes;
- non-identifiable parameters;
- failed fabrication assumptions;
- false numerical improvements;
- defect interactions that did not reproduce;
- phase paths contradicted by experiment;
- capacity-frontier saturation events;
- OAK failures and the intervention required before retry.

Runtime campaigns write JSONL ledgers into their output directory. Checked-in records must be anonymized, reproducible, and useful as anti-datasets; do not commit secrets, proprietary data, sensitive personal information, or unpublished patent-enabling details.
