## R0.3 residuals

### Residual Field

`compile_residual_field` returns required capabilities that are still
unreachable, rules blocked on missing prerequisites, and requirements that no
declared rule can produce.

### Minimal Generating Basis

`minimal_generating_basis` searches subsets in increasing cardinality and is
therefore exact **only inside the supplied finite seed universe**. The default
guard refuses more than 16 candidate seeds.

If `required` is omitted, the target is the full closure reachable from the
original seed set. This makes compression auditable: a seed is removed only
when the declared rule system can reconstruct the target without it.

### Finite renormalization

`renormalize_seed_set` reduces a seed set while preserving declared
observables, then repeats the same reduction on the reduced candidate universe.
`stable_under_second_pass=True` means finite idempotence for this operator and
this declared problem. It is **not** a theorem about physical renormalization,
universal architecture, or global optimality.

## Proof-carrying morphogenesis

`compile_morphogenesis_receipt` reuses MetaScience's existing:

- representation arbitrage with declared solve/transform costs, round-trip
  loss and invariant retention;
- transform certificate with declared invariants, error bound, domain and
  provenance.

A receipt additionally requires evidence references, bounded uncertainty and
cost/risk, and a rollback path. `PASS` means those declared structural gates
pass. It does **not** prove that the transformation is an improvement, that its
claims are scientifically true, or that its representation is globally best.
