# Ω-PURE-MATH-T∞ — R0.2 crystallization

R0.2 promotes four previously deferred directions into finite executable laboratories while preserving strict OAK boundaries.

## 1. Associahedron / bracket-space geometry

`bracket_spectrum.py` now builds the elementary rotation graph generated by

\[
((ab)c) \longleftrightarrow (a(bc)).
\]

For four ordered leaves there are five Catalan parenthesizations; the resulting rotation graph is the pentagonal 1-skeleton of the associahedron. The implementation exposes:

- `tree_signature`;
- `rotation_neighbors`;
- `rotation_graph`;
- `rotation_graph_connected`;
- `edge_associator_field`.

The edge field assigns a metric defect to every elementary reassociation. It vanishes for associative operations and can localize where a non-associative operation changes value across bracket space.

**OAK boundary:** finite vanishing on sampled values does not prove global associativity.

## 2. Finite invariant completeness — T5 laboratory

`finite_classification.py` adds exact finite orbit computation under declared action generators. For a finite universe \(X\), it can test whether an invariant satisfies

\[
I(x)=I(y) \iff x,y\text{ lie in the same orbit}.
\]

It also returns collisions and exhaustively searches inclusion-minimal complete invariant families from a supplied dictionary.

The benchmark action \(x\mapsto -x\) on \(\{-2,-1,0,1,2\}\) verifies that `abs` and \(x^2\) are complete on that declared finite universe, while parity produces collisions.

**OAK boundary:** this is a finite classification experiment, not a theorem about an infinite carrier.

## 3. Exact finite factorization trees

`factor_tree.py` upgrades flat witnesses into explicit decomposition trees. Given a finite brick set and decomposition rules it computes a minimum-leaf tree, rejects active cyclic recursion paths, and exposes:

- leaf count;
- depth;
- canonical tree signature;
- a simple subtree-signature distance.

This creates an executable base for Ω-FACTOR-TREE-T∞ without claiming uniqueness or optimal algorithms for arbitrary categories.

## 4. LOG/EXP federation

`logexp_adapter.py` connects Ω-PURE-MATH-T∞ to the repository's existing `omega_logexp_morph_t` kernel instead of duplicating matrix exponentials/logarithms.

The adapter performs

\[
A \xrightarrow{\exp} T \xrightarrow{\log} \widehat A
\xrightarrow{\exp} \widehat T
\]

and reports both generator and transformation reconstruction residuals.

It inherits the existing explicit Mercator gate

\[
\|T-I\|_\infty < 1,
\]

so no global matrix-logarithm claim is introduced.
