## M⁻ seeds

1. **False promotion:** a finite sample with zero associativity defect does not
   prove global associativity.
2. **Unknown ≠ irreducible:** no recorded factorization is not proof that an
   object is a brick.
3. **Feature collision ≠ equivalence:** equal Structural DNA signatures are not
   proof of isomorphism.
4. **CVCD matrix ≠ tensor automatically:** transformation laws are required.
5. **Compression score ≠ truth score:** a compact theory can be false.
6. **LOG/EXP ≠ universal:** transformations can have multiple, local or no
   admissible logarithms.
7. **New name ≠ new mathematics:** prior art must be mapped before novelty
   language.
8. **Executable certificate ≠ proof of hidden premise:** T1 code verifies a
   witness inequality, not minimality of unknown factorizations.
