# Axiome‑Tristan BOOK0 — candidate regenerative kernel

## Candidate basis

R0.1 proposes, but does not prove minimality of:

`K_A = {OBSERVE, REPRESENT, CLAIM, CONTRAST, PROBE, VERIFY, REMEMBER, REGENERATE}`

Each primitive must survive ablation against explicit required capabilities. If deleting a primitive preserves the same verified closure at lower cost and risk, the smaller basis should replace it.

## Probe-relative fixed point

The current regeneration criterion is:

`Rebuild(K_A, artifact) ≈ artifact`

relative only to this declared ProbeFamily:

- `CAN_SERIALIZE`
- `CAN_REPLAY`
- `CAN_COMPARE`
- `CAN_AUDIT`

A zero serialization/replay residual is **not** a global proof of semantic equivalence, scientific correctness, completeness, or future behavior outside these probes.

## MetaStop

A persistent meta-layer survives only when:

`OOD_VerifiedGain > Complexity + Compute + Risk + HumanFriction + EpistemicDebt`

Otherwise the preferred operations are `STOP`, `MERGE`, `PRUNE`, or `SIMPLIFY`.

## Regenerative memory doctrine

Prefer storing the minimum regenerative structure needed to reconstruct useful capability:

- generative rules and schemas;
- evidence and provenance required for audit;
- M+ successes with bounded domains;
- M− failures as detection rules and countermeasures;
- residuals and open proof obligations;
- rollback/version lineage.

Do not preserve historical complexity as active architecture merely because it once existed.

## Authority boundary

`RegenerationReceipt.authoritative = false` in R0.1.

Self-reconstruction is evidence about deterministic software behavior under declared probes. It does not grant self-promotion, publication authority, scientific authority, financial authority, or permission to modify external systems.
