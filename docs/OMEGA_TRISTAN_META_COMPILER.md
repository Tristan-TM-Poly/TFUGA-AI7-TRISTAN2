# Ω Tristan Meta-Compiler — Architecture

## Control plane vs execution plane

- **Axiome-Tristan / epistemic control plane**: Claim, Evidence, Model, Falsifier, uncertainty, version, provenance, promotion gates.
- **Tristan Web / execution plane**: Capability, Actor, Tool, Simulation, Experience, World, Interaction and session execution.
- **Reality anchors** feed observations back to the control plane.

## Mother loop

`INTENT -> RESIDUAL -> CLAIM/MODEL -> GENERATE -> COUNTERGENERATE -> PROBE -> VERIFY -> CAPABILITY -> EXPERIENCE/ACTION -> REALITY -> RESIDUAL`

Orthogonal lifecycle:

`VERSION -> RECEIPT -> DISTILL -> PRUNE -> REGENERATE`

## Meta-generation

Meta-generation is valid only when it creates a new reusable transformation or capability. Naming another domain-specific `XGenome` does not by itself justify a new primitive.

## Meta-automation

Automation is a policy over observability, reversibility, risk and authority. Technical feasibility never implies permission.

## Meta-regeneration

Regeneration is measured against a frozen probe family. BOOK0 is a candidate minimal seed, not an object exempt from ablation.
