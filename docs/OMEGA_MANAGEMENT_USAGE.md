# Ω Management Usage

Use the package to structure observations, compare weak proxies to direct outcomes, compute bounded local indices, rank reversible interventions and emit receipts.

Recommended workflow:
`observe -> define direct outcome -> identify residual -> generate candidates -> apply hard gates -> rank -> obtain real authority -> act -> re-observe -> record receipt`.

Do not use the package as an automatic employee evaluator. A score is not a diagnosis of motivation, character, leadership, legal compliance or future performance.

For artifact expansion, run the 2^n ladder and always inspect the n+1 probe before claiming saturation.
