# Ω-UVTC-T∞ R0.1 — Universal Verified Transformation Compiler

## Scope

R0.1 compiles intent and existing Tristan execution plans into a typed **Universal Transformation IR (UTIR)** built from 16 semantic primitives across six kernels.

It deliberately **reuses** already-merged foundations:

- Ω-DISCOVERY-OPERATING-SYSTEM-T∞²: epistemic type checking and dependency-aware scientific rebuilds;
- Ω-COGNITIVE-COMPUTER-T∞: cognitive ISA/runtime and crystallization substrate;
- Ω-CAPABILITY-OS-T∞: capability planning, authority lattice and external-action receipts.

UVTC is a coordinating compiler layer, not a replacement for those systems.

## Semantic ISA

`STATE GOAL REPRESENT SEARCH TRANSFORM COMPOSE BRANCH MEASURE FALSIFY PROVE OAK MEMORIZE RESIDUAL CRYSTALLIZE LEARN_PRIMITIVE ALLOCATE`

The set is a **canonical R0.1 semantic ISA**, not a proof of mathematical irreducibility.

## GO MAX / GO MIN

GO MAX expands verified reachable capability. GO MIN removes structural debt only when the removal is evidence-safe. The superoptimizer includes deterministic common-subproblem elimination, peephole representation elimination and uncertainty-aware speculative pruning.

Independent replication and instructions carrying non-elidable side effects are never silently deduplicated or pruned.

Power density is an explicit policy metric:

`(verified_frontier_gain + reachable_value_gain) / (compute + K0 + proof_debt + uncertainty_debt + risk)`.

It is not a natural law or universal scalar measure of scientific value.

## KnowledgeMake

Knowledge nodes are content-addressed and bitemporal. R0.1 computes strongly connected components, condenses them to a DAG, and cascades `STALE` status only through dependency descendants. Hash equality establishes identity of declared content, not truth.

## Crystallization boundary

R0.1 emits `CRYSTALLIZE` as a typed semantic instruction. A richer GOArtifact/ReproCapsule container remains a next bounded frontier; R0.1 does not pretend that a hash proves truth.
