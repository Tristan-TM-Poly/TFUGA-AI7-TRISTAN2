# Ω-ZETA-SQUARE-T∞ R2 — Certificates, Padé, Jacobi, M−

Status: `research-toolkit`, `no-RH-solution-claimed`.

R2 turns the centered-square branch from a geometry/moment prototype into a finite exact reconstruction laboratory.

## 1. Corrected PSD logic

The R1 diagnostic reported leading principal Hankel minors. Those are useful observables, but nonnegative leading principal minors alone do not characterize positive semidefiniteness in the semidefinite case.

R2 therefore:

- uses an LDL^T residual-aware PSD test for finite floating-point diagnostics;
- adds exact all-principal-minor certificates for supplied `int`/`Fraction` moment data;
- stores a concrete M− counterexample: the Hankel matrix generated by `[0,0,-3,-3,-3]` has leading determinants `0,0,27` but a principal minor on indices `(0,2)` equal to `-9`.

This is a reusable anti-false-proof artifact.

## 2. Exact finite Stieltjes certificates

For inverse moments `p_k`, define `m_k=p_(k+1)` and the finite Hankel blocks

\[
H^{(0)}_{ij}=m_{i+j},\qquad H^{(1)}_{ij}=m_{i+j+1}.
\]

`exact_stieltjes_certificate` checks every principal minor exactly for rational input. Its epistemic status is deliberately

`EXACT_FINITE_MOMENT_CERTIFICATE_ONLY`.

It certifies the matrices built from the supplied rationals, not that those rationals are exact values derived from \(\xi\).

## 3. Padé/Stieltjes bridge

Using

\[
L(u)=\frac{\Theta'(u)}{\Theta(u)}
=p_1-p_2u+p_3u^2-\cdots,
\]

R2 constructs the exact `[n-1/n]` Padé approximant from `p_1,...,p_{2n}`.

For a finite atomic model with \(\lambda_j=\gamma_j^{-2}\),

\[
L(u)=\sum_j\frac{\lambda_j}{1+\lambda_j u},
\]

so an order matching the number of atoms exactly recovers the rational denominator. This gives an OAK test bed for future pole-reality and residue-positivity constraints.

## 4. Jacobi reconstruction

R2 reconstructs monic orthogonal polynomials for the moment functional

\[
m_k=p_{k+1}
\]

and the recurrence

\[
P_{n+1}(x)=(x-\alpha_n)P_n(x)-\beta_nP_{n-1}(x).
\]

The finite Jacobi characteristic polynomial is then generated exactly. On synthetic finite positive atomic measures its roots recover the support nodes.

OAK boundary: a finite matrix reconstructed from supplied moments is **not** an independent Hilbert–Pólya operator.

## 5. CLI

Examples with an exact two-atom model:

```bash
P="13/36 97/1296 793/46656 6817/1679616"
python -m omega_zeta_square_t exact-cert --hankel-size 2 $P
python -m omega_zeta_square_t pade --order 2 $P
python -m omega_zeta_square_t jacobi --size 2 $P
```

Every emitted object keeps `proves_rh=false`.

## 6. R3 target

The next hard step is not more finite reconstruction. It is **provenance-preserving certification from the analytic source**:

\[
\xi^{(2m)}(1/2)
\to \text{rigorous intervals for }a_m
\to \text{rigorous intervals for }p_k
\to \text{certified signs of Hankel determinants}
\to \text{Padé/Jacobi interval constraints}.
\]

Only after that layer is rigorous should CVCD search for minimal forcing sets or an off-line-zero finite witness theorem.
