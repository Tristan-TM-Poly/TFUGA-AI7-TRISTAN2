# Ω-META-MORPHOGENESIS-T∞ — v1

## Status

Engineering MVP / candidate crystal. This layer extends the existing Ω Tristan Meta-Compiler and reuses the canonical `omega_morphogenesis` proof-carrying kernel. It does not create a parallel authority system and does not claim autonomous self-improvement.

## Objective

Turn meta-generalization, meta-generation, meta-automation, meta-regeneration, meta-improvement and meta-crystallization into one bounded execution model:

```text
REALITY
→ RESIDUAL
→ MORPHGENOME
→ GENERATE / COUNTERGENERATE
→ PROOF-CARRYING TRANSITION
→ OAK
→ CRYSTAL or HOLD
→ M+/M-/M?
→ ABLATE / REGENERATE
```

The persistent object is not every generated artifact. It is the smallest verified seed that can reconstruct required capabilities while preserving evidence and provenance.

## Generic MorphGenome

`MorphGenome` generalizes theory, agent, workflow, institution, business, compiler and other domain genomes without asserting that they are semantically identical. Domain-specific constraints remain explicit.

A MorphGenome carries:

- purpose and state schema;
- operators and constraints;
- evidence contracts;
- resources and declared permissions;
- memory references;
- regeneration rules;
- parent lineage.

A genome is descriptive. `Genome != Authority`.

## Proof-carrying morphogenesis

Every candidate transition is converted to the existing `ProofCarryingTransformation` ABI and judged by the canonical `MorphogenesisKernel`.

Required boundaries include:

```text
Generator != Judge
Generated != Verified
Simulation != Reality
Capability != Authority
Output epistemic status <= supporting evidence status
High-risk mutation => rollback or compensation
```

A `MorphogenesisReceipt` records before/after hashes, generator/verifier identity, authority envelope, evidence references, tests, uncertainty, utility, persistence decision and rollback. It always starts with:

```text
external_action_performed = false
auto_promoted = false
```

## Complexity rent

A candidate can be accepted by safety/truth gates yet still fail to persist. Persistence requires the existing transformation utility to exceed explicit complexity rent.

This prevents:

```text
more META => automatically better
```

The intended rule is:

```text
new persistent structure must buy measurable verified capability, information, transfer, regenerability, optionality or future work eliminated.
```

## M+ / M- / M?

The causal memory surface explicitly separates:

- `M+`: useful/validated outcomes;
- `M-`: failed, dangerous or falsified paths plus reusable prevention rules;
- `M?`: unresolved uncertainty that must remain live rather than being forced into PASS/FAIL.

`negative_invariants()` only compresses already-declared M- generalizations. It does not manufacture causal laws from failure text.

## Crystallization

A capability can crystallize only when the morphogenesis receipt is accepted, pays complexity rent, contains evidence references and contains tests.

A `CapabilityCrystal` remains challengeable. New evidence can invalidate upstream support and the dependency blast-radius mechanism identifies downstream claims/crystals requiring review.

```text
Crystal != EternalTruth
```

## Apoptosis

Apoptosis is deliberately non-destructive in v1.

A component can become `ELIGIBLE_FOR_REVIEW` only when:

- regeneration closure is complete;
- evidence is preserved;
- provenance is preserved;
- marginal verified capability is below the configured survival threshold relative to maintenance/complexity/risk.

Even then:

```text
automatic_delete = false
```

## FORGET+

`FORGET+` is represented as `REGENERATE_ON_DEMAND`, never as automatic deletion. It is allowed only when regeneration closure meets the threshold and both evidence and provenance remain preserved.

## Regeneration depth

Candidate vocabulary:

```text
R0 artifact
R1 component
R2 system
R3 capability
R4 compiler
R5 ecology
R6 constitution-aware regeneration
R7 minimal seed candidate
```

These are capability claims that must be tested per artifact. A label alone does not establish regeneration depth.

## Meta-stop

The pre-existing MetaStop remains authoritative for new meta-level creation:

```text
if expressible_by_current_kernel:
    STOP
else:
    create new meta-level only when verified out-of-sample gain > added meta complexity
```

## OAK non-claims

This v1 does not establish:

- autonomous general intelligence;
- scientific truth of generated theories;
- permission to act on external systems;
- safe automatic deletion;
- optimality of the selected representation;
- universal applicability of MorphGenome;
- real-world superiority over conventional engineering/research workflows.

Those require external benchmarks and domain-specific evidence.
