# Critical-infrastructure security boundary

## Green

Open publications, open datasets, regional aggregates, educational models, synthetic topology and generated worlds.

## Amber

Composite datasets, precise coordinates, inferred vulnerabilities, customer traces or asset-level fragility. These require aggregation and security review and are blocked in public-data-only mode.

## Red

SCADA/EMS, protection settings, credentials, non-public topology, access paths, exploit details, live commands and operational procedures. R0.1 refuses these categories.

Security is evaluated by information composition, not only by the sensitivity label of each individual source.
