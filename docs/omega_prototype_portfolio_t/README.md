# Ω-PROTOTYPE-PORTFOLIO-T∞ R0.1 MAX

A deterministic, evidence-aware and OAK-safe portfolio operating layer for Tristan prototypes.

```text
repository / PR / commit observations
→ typed prototype records
→ non-compensatory maturity gates
→ science / engineering / product / integration scores
→ dependency and overlap graph
→ diversified crystallization plan
→ JSON / JSONL / GraphML / Markdown / SHA-256 receipts
→ M− and next evidence action
```

## Why

The portfolio already contains executable scientific, mathematical, GitHub, Web, startup and research systems. The next constraint is not ideation: it is distinguishing structured ideas from tested software, internal fixtures from external evidence, payments from retention, and logical frontiers from completed work.

## Core contract

Each prototype carries:

- exact repository and evidence reference;
- 18 bounded dimensions from truth and code to integration and falsifiability;
- 12 observed boolean signals;
- claim status and limitations;
- risks and M−;
- typed dependency/overlap relations;
- one bounded next action with expected evidence.

## Maturity ladder

```text
P0 idea
P1 structured
P2 executable
P3 tested
P4 benchmarked
P5 external evidence
P6 collected payment + product evidence
P7 repeat usage + retention
P8 independently certified and maintainable canon
```

A high score cannot compensate for a missing gate. Code cannot replace tests. Tests cannot replace baselines. Internal CI cannot replace independent validation. Payment cannot replace retention.

## OAK boundaries

- score != probability of truth;
- CI green != scientific validation;
- same signature != semantic equivalence;
- logical address != executed evidence;
- generated record != discovery;
- invoice != payment;
- payment != retention;
- plan != authority to merge, publish, deploy, contact, spend or file IP;
- every source snapshot can become stale and must be refreshed.

## Validation
