# Ω-RE-T∞ R0.5 — Active Bayesian, Grammar, Nonlinear and Public-Evidence Layer

## Status

`SOFTWARE_RESEARCH_ARCHITECTURE / SYNTHETIC_OR_AUTHORIZED_SYSTEMS_ONLY`

R0.5 expands the merged R0.1–R0.4 stack without replacing it. It focuses on twelve missing proof surfaces:

1. active probabilistic hypothesis discrimination;
2. residual-triggered Bayesian model-class expansion;
3. bounded context-free grammar compatibility;
4. nonlinear hybrid dynamics with explicit fit and simulation envelopes;
5. distributed work leases with retry semantics;
6. publicly verifiable one-time integrity receipts;
7. software calibration of a deterministic 1,024-case frontier;
8. probabilistic CFG likelihood and Viterbi evidence;
9. protocol negotiation with downgrade prevention;
10. drift monitoring across calibration windows;
11. adversarial worker-evidence auditing;
12. adaptive finite campaigns over an indexable frontier without a permanent total cap.

None of these modules claims access to inaccessible internals. A selected model remains the best member of a declared class under declared evidence.

## Active probabilistic learning

Finite hypotheses expose outcome likelihoods for authorized experiments. R0.5 calculates normalized priors and posteriors, predictive distributions, posterior entropy, expected information gain, cost/risk penalties and explicit stopping causes. Posterior concentration is conditional on the model class; missing classes remain a first-class failure mode.

## Model-class expansion

A high residual may trigger child-model generation. Expansion is bounded by parent linkage, strictly increasing complexity, maximum complexity, duplicate rejection, posterior beam width and provenance labels. Generated classes are candidates, not discoveries.

## Bounded and probabilistic CFGs

`BoundedCFG` provides deterministic CYK recognition and finite generation under token/sentence budgets. `ProbabilisticCFG` adds inside probability, Viterbi witnesses and seeded bounded sampling. Bounded corpus acceptance or likelihood does not prove equivalence with an original parser or unrestricted language.

## Nonlinear hybrid systems

R0.5 supports degree-1 to degree-3 polynomial vector fields, ridge-regularized fitting, Euler simulation, guarded mode changes, resets, state envelopes and underdetermination rejection. The model is a low-order numerical hypothesis, not validated physics or a safety controller.

## Lease workers and adversarial audit

The lease queue demonstrates pending item → bounded lease → heartbeat/expiry → retry → one accepted result commit per item. Execution is at-least-once; accepted commits are exactly once per item identifier. Synthetic audits reject unknown leases, mismatches, staleness, revocation, duplicate commits and equivocation. This does not prove Byzantine tolerance under real network partitions.

## Public receipts

R0.5 includes SHA-256 Lamport one-time signatures. Verification requires only receipt, signature and public commitments; key reuse is rejected. This educational implementation is not a substitute for reviewed Ed25519 libraries, PKI, hardware-backed keys, timestamp authorities or legal notarization. Deterministic seeds are for tests only.

## RE-1024 software calibration

The calibration fixture creates exactly 1,024 deterministic software cases across 16 families and reports Brier score, log loss, calibration errors, threshold accuracy, bins, progressive windows and a digest.

```text
logical_cases = 1024
materialized_cases = 1024
executed_cases = 1024
software_tested_cases = 1024
scientifically_verified_cases = 0
```

These are synthetic software executions. They do not retroactively convert the R0.3 atlas into external experiments.

## Protocol, drift and orchestration

Negotiation selects the highest mutually declared version satisfying capability and anti-downgrade policy. Drift windows use Jensen-Shannon divergence, PSI, Brier delta and calibration-error delta. The frontier is indexable with `permanent_total_cap = null`, while every actual run remains finite under explicit item, cost and failure envelopes.

## OAK promotion gates

Promotion is blocked when an experiment is unauthorized; budgets are exceeded; posterior concentration is presented as internal identity; expansion loses provenance; CFG claims exceed bounds; polynomial fitting is underdetermined; simulation leaves its envelope; stale leases commit; a Lamport key is reused; a secret seed enters Git; software calibration is called scientific verification; or a finite run is described as infinite computation.

## Negative memory M−

- informative-looking but unauthorized interventions;
- certainty caused by omitted model classes;
- grammar overgeneralization from sparse examples;
- nonlinear instability hidden by training residuals;
- duplicate work after lease expiry;
- exactly-once execution confused with exactly-once accepted result;
- Lamport key reuse;
- integrity confused with truth;
- 1,024 software cases confused with 1,024 physical experiments.
