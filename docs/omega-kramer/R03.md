## 2. Polynomial-time division-free characteristic circuit

For

\[
p_A(\lambda)=\det(\lambda I-A)
=\lambda^n+c_1\lambda^{n-1}+\cdots+c_n,
\]

R0.3 constructs a Berkowitz-style recursive circuit using only additions and multiplications. No matrix inversion and no symbolic pivot division is introduced.

For a block decomposition

\[
A=
\begin{pmatrix}
a&R\\C&M\end{pmatrix},
\]

the recursion uses the scalar moments

\[
s_k=RM^{k-1}C
\]

inside the lower-Toeplitz Berkowitz transform. The straightforward implementation is polynomial-growth (bounded by \(O(n^4)\) arithmetic work here) rather than the exponential subset-state growth of R0.1/R0.2.

The determinant is recovered from the constant characteristic coefficient:

\[
\boxed{\det A=(-1)^n c_n.}
\]

Because the entire determinant output is still an arithmetic circuit, reverse automatic differentiation gives

\[
\boxed{
\frac{\partial\det A}{\partial a_{ij}}=C_{ij},
\qquad
\nabla_A\det(A)=\operatorname{adj}(A)^T.
}
\]

Thus the new polynomial-growth backend preserves the central Kramer-Tristan principle:

\[
\boxed{\text{compile once}\to\det+\text{all first derivatives}.}
\]

## 3. Static circuit crossover — representation metric, not speed claim

`backend_complexity_atlas()` builds both generic circuits and records hash-consed operation nodes.

For the current implementation, the Berkowitz-style circuit becomes no larger than the subset circuit around \(n=7\)–\(8\), and is smaller by \(n=8\) on this metric.

This means only:

> the polynomial circuit becomes more compact than the current subset circuit under this static node-count representation.

It does **not** mean:

- lower wall-clock time on every machine;
- better cache behavior;
- lower memory under every evaluator;
- superiority over Bareiss, LU, QR, sparse solvers or specialized symbolic systems.

Those require separate empirical campaigns.

## 4. Exact multilinear determinantal derivatives

R0.2 computes the exact directional polynomial

\[
\det(A+tH)=\sum_{k=0}^{n}Q_k(H)t^k
\]

with

\[
Q_k(H)=\frac1{k!}D^k\det(A)[H,\ldots,H].
\]

R0.3 polarizes the homogeneous component \(Q_k\). For directions \(H_1,\ldots,H_k\),

\[
\boxed{
D^k\det(A)[H_1,\ldots,H_k]
=
\sum_{S\subseteq\{1,\ldots,k\}}
(-1)^{k-|S|}
Q_k\!\left(\sum_{i\in S}H_i\right).
}
\]

This creates an exact finite multilinear probe without materializing the full rank-\(2k\) tensor.

OAK boundary: the polarization cost is exponential in derivative order \(k\), even though the underlying determinant backend can be polynomial in matrix dimension. R0.3 therefore treats it as a bounded higher-order probe, not a universally efficient tensor compiler.

## 5. Mixed discriminant convention

R0.3 defines explicitly

\[
\boxed{
D(A_1,\ldots,A_n)
=\frac1{n!}
\frac{\partial^n}{\partial t_1\cdots\partial t_n}
\det\!\left(\sum_i t_iA_i\right)\Big|_{t=0}.
}
\]

With this convention,

\[
\boxed{D(A,\ldots,A)=\det A.}
\]

The implementation tests that normalization exactly over rational fixtures.

## 6. Higher adjugates as Hodge/complementary compounds

R0.2's generalized cofactor layer opens \(k\) row indices and \(k\) column indices. R0.3 cross-checks it against the \((n-k)\)-th compound matrix.

For open index sets \(I,J\),

\[
\operatorname{Adj}^{[k]}(A)_{I,J}
=
(-1)^{\Sigma I+\Sigma J}
\det A_{I^c,J^c}.
\]

Therefore the higher-adjugate tower is dual to the exterior/compound tower:

\[
\boxed{
\operatorname{Adj}^{[k]}(A)
\longleftrightarrow
\wedge^{n-k}A
}
\]

up to complementary-index ordering and the displayed sign convention.

R0.3 audits every order \(0\le k\le n\) on each supplied fixture and cross-checks the first nonzero higher-cofactor order with the exact nullity from the R0.2 Singularity Ladder.

## 7. Proof-carrying rewrite portfolio

R0.3 introduces rewrite certificates rather than silently replacing expressions.

### 7.1 Global rank-one polynomial update

For all square \(A\), including singular matrices,

\[
\boxed{
\det(A+uv^T)=\det A+v^T\operatorname{adj}(A)u.
}
\]

This is preferred over an inverse-based matrix determinant lemma when a global polynomial identity is required.

### 7.2 Sylvester dimension reduction

For \(U\in\mathbb F^{n\times k}\), \(V\in\mathbb F^{k\times n}\),

\[
\boxed{
\det(I_n+UV)=\det(I_k+VU).
}
\]

When \(k\ll n\), this provides a potentially dramatic exact reduction in determinant dimension without an invertibility guard.

### 7.3 Kronecker factorization

For square \(A\in\mathbb F^{n\times n}\), \(B\in\mathbb F^{m\times m}\),

\[
\boxed{
\det(A\otimes B)=\det(A)^m\det(B)^n.
}
\]

### 7.4 Guarded Schur complement

For

\[
M=\begin{pmatrix}A&B\\C&D\end{pmatrix},
\]

if

\[
\det A\ne0,
\]

then

\[
\boxed{
\det M=\det A\,\det(D-CA^{-1}B).
}
\]

Unlike the three global polynomial rewrites above, this is a local rational representation. The compiler therefore stores the guard `det(A11) != 0` in a `GuardLedger`. If the guard is false, the rewrite is refused instead of manufacturing an invalid expression.

This is the beginning of **proof-carrying equality saturation**: candidate rewrites are associated with identities, conditions, residuals and provenance rather than being treated as interchangeable strings.

## 8. ROOTFLOW spectral bridge

For a parameterized matrix \(A(\theta)\), eigenvalues are roots of

\[
P(\lambda;\theta)=\det(\lambda I-A(\theta)).
\]

R0.3 exports the exact characteristic coefficients in the convention already used by `Ω-ROOTFLOW-T∞`:

\[
[a_0,a_1,\ldots,a_n]
\quad\text{for}\quad
P(\lambda)=\sum_{k=0}^{n}a_k\lambda^k.
\]

The bridge performs independent exact probe checks

\[
P(\lambda_*)\stackrel{?}=\det(\lambda_*I-A)
\]

at several integer values before declaring the coefficient packet ready.

This yields the executable composition

\[
\boxed{
A(\theta)
\rightarrow
\det(\lambda I-A(\theta))
\rightarrow
\text{exact coefficient packet}
\rightarrow
\Omega\text{-ROOTFLOW-T}^{\infty}
\rightarrow
\lambda_i(\theta).
}
\]

OAK: R0.3 certifies the polynomial handoff, not numerical eigenvalue tracking, branch continuation or physical interpretation. Those remain ROOTFLOW responsibilities.

## 11. OAK stop conditions

Do not claim the Berkowitz backend is universally faster because its static circuit has fewer operation nodes for some \(n\).

Do not use an inverse-based rewrite when its guard is false or unknown.

Do not confuse structural rank with exact rank.

Do not interpret mixed derivatives as a novel mixed-discriminant theorem.

Do not treat ROOTFLOW coefficient compatibility as certified spectral continuation.

Do not expand the full higher-derivative tensor by default when bounded probes or compounds answer the query more cheaply.
