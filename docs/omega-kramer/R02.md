## 2. Division-free arithmetic-circuit IR

`build_determinant_circuit(n)` creates a generic determinant straight-line program whose only arithmetic operations are `add` and `mul`. Constants and variables are hash-consed, and commutative binary nodes use a canonical argument order.

The current circuit still uses the R0.1 subset-state recurrence, hence remains exponential. The improvement is representational: determinant and reverse gradient now live in an explicit reusable arithmetic-circuit IR rather than only in a numeric dynamic program.

For the generic 5x5 circuit, the deterministic regression fixture contains:

- 184 total nodes;
- 25 variable nodes;
- 49 add nodes;
- 107 multiply nodes;
- 80 subset transitions.

No division node exists.

## 3. Adjugate from the same circuit

The classical identity

\[
\frac{\partial\det A}{\partial a_{ij}}=C_{ij}
\]

is executed directly by reverse mode on the determinant circuit. The resulting gradient is the cofactor matrix and its transpose is the adjugate.

R0.2 cross-checks the result against three independent views:

1. exact Bareiss determinant;
2. direct cofactor/Bareiss adjugate oracle;
3. the R0.1 subset reverse-AD path.

The purpose is not to claim that reverse AD proves a new theorem. It makes sharing explicit and testable.

## 4. Shared-computation metrics

R0.2 emits two exploratory deterministic metrics:

\[
SCR=\frac{\text{explicit Leibniz leaf baseline}}{\text{circuit operation nodes}}
\]

and

\[
SCG=1-\frac{\text{circuit operation nodes}}{\text{explicit Leibniz leaf baseline}}.
\]

The baseline counts a determinant plus separately expanded cofactor determinants. These metrics compare combinatorial representation sizes only. They are **not runtime speedups, optimality results or complexity lower bounds**.

## 5. Exact directional determinantal jet

For a direction matrix `H`, R0.2 constructs exactly

\[
p(t)=\det(A+tH)=\sum_{k=0}^n c_k t^k
\]

from `n+1` exact determinant evaluations and rational interpolation.

It reports

\[
p^{(k)}(0)=k!c_k.
\]

An additional unused interpolation point is evaluated and required to have zero exact residual.

This is the first executable `Determinantal Jet` surface. R0.2 computes a one-direction restriction, not the full multilinear derivative tensor.

## 6. Higher cofactors as open-index contractions

`generalized_cofactors(A, k)` opens `k` row indices and `k` column indices and stores the signed complementary `(n-k)x(n-k)` minors:

\[
C_{I,J}=(-1)^{\sum I+\sum J}\det A_{I^c,J^c}.
\]

Endpoints:

- `k=0`: the single entry is `det(A)`;
- `k=1`: the matrix is the ordinary cofactor matrix, whose transpose is `adj(A)`;
- `k=n`: the single complementary empty determinant is `1`.

This is the executable bridge toward higher adjugates, open-index tensor contractions, mixed determinants and exterior-power duality.

## 7. Singularity Ladder

Let `rank(A)=r` for an `n x n` matrix. A nonzero `(n-k)x(n-k)` minor first exists at

\[
k=n-r.
\]

R0.2 therefore defines the first nonzero higher-cofactor order and checks it against exact nullity:

\[
\boxed{k_{first}=\operatorname{nullity}(A)}.
\]

This converts the ordinary Cramer stop condition `det(A)=0` into a stratified diagnostic:

```text
nullity 0 -> determinant nonzero -> ordinary Kramer layer
nullity 1 -> determinant zero, ordinary adjugate can remain nonzero
nullity 2 -> determinant and ordinary adjugate vanish; order-2 higher cofactors carry the first witness
...
```

The implementation returns an explicit nonzero complementary-minor witness.

## 8. Structural rank versus exact rank

R0.2 compiles the nonzero support of `A` into a bipartite row/column graph and computes a maximum-cardinality matching by exact combinatorial augmentation.

It records both:

- `structural_rank`: maximum matching size of the support pattern;
- `exact_rank`: rational row-reduction rank of the actual entries.

The difference is important. For

\[
\begin{pmatrix}1&1\\2&2\end{pmatrix},
\]

structural rank is 2 while exact rank is 1. The router therefore refuses a Cramer division even when the sparsity pattern alone could support full rank.

## 9. Block/support structure miner

The bipartite support graph additionally records:

- density and nonzero count;
- zero rows/columns;
- diagonal/upper/lower triangular structure;
- symmetry;
- connected row/column support components;
- balanced support blocks.

Balanced disconnected components are a deterministic signal for block decomposition before symbolic expansion.

## 10. First backend router

The R0.2 router is deliberately bounded and claim-safe:

```text
rectangular -> compound/rank analysis
exact singular -> singularity ladder
 diagonal -> diagonal closed form
 triangular -> triangular closed form
 disconnected balanced support -> block decomposition
 small exact dense -> subset circuit + reverse AD
 large sparse -> sparse fraction-free candidate
 large dense -> Bareiss/Berkowitz candidate
```

This is a heuristic research router. It does not claim optimal backend selection.

## 11. Proof-carrying rational simplification

R0.2 adds exact univariate polynomial arithmetic over `Fraction`:

- addition / multiplication / evaluation;
- Euclidean division;
- monic polynomial GCD;
- rational-function cancellation.

The critical difference from an ordinary simplifier is the `DomainLedger`.

For example,

\[
\frac{(t-1)(t+2)}{(t-1)(t+3)}
\rightarrow
\frac{t+2}{t+3},
\]

but the output retains:

- original denominator `(t-1)(t+3)`;
- cancelled factor `(t-1)`;
- reduced denominator `(t+3)`;
- original guard `den_original(t) != 0`.

Thus `t=1` cannot silently re-enter the domain after cancellation.
