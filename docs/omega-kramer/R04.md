## 1. R0.4 objective

R0.1-R0.3 established a shared determinant/adjugate/Kramer stack, division-free circuits, higher adjugates, exact determinantal jets, proof-carrying rewrites and a characteristic-polynomial bridge to Ω-ROOTFLOW-T∞.

\[
\boxed{
\text{representation}\to\text{measurement}\to\text{structure}\to\text{rewrite}\to\text{spectral response}
}
\]

The design rule is deliberately conservative:

> A faster observation is not an algorithmic theorem; a structural heuristic is not a canonical decomposition; a simplified rational form never erases its original domain.

## 2. OAKBench: measured, but not overclaimed

`benchmark_matrix()` evaluates exact determinant backends under the same Python process:

- Bareiss exact elimination;
- the R0.2 subset circuit when `n <= 8`;
- the R0.3 Berkowitz-style polynomial-growth circuit.

For each applicable backend R0.4 records:

- observed median/min/max nanoseconds;
- traced peak Python memory;
- exact determinant agreement;
- compile+evaluate versus evaluate-after-compile for reusable circuits;
- static operation-node count;
- maximum bit length of exact rational intermediate values.

The key separation is

\[
\boxed{
\text{static expression/circuit metric}
\ne
\text{numeric intermediate swell}
\ne
\text{wall-clock measurement}.
}
\]

CI checks only exactness and schema-level invariants. It never requires one backend to outrun another.

`oakbench_atlas()` currently includes dense, banded, block, singular and Vandermonde families.

## 3. Bareiss intermediate swell

The instrumented Bareiss oracle records the maximum bit length appearing in exact rational intermediates.

This is useful because two algorithms with similar arithmetic counts can create very different intermediate numbers.

However:

\[
\boxed{
\text{bit length of evaluated rationals}
\ne
\text{symbolic expression-tree size}.
}
\]

R0.4 reports the metric only under its proper interpretation.

## 4. DM-inspired sparse structural decomposition

For the nonzero pattern of a matrix, R0.4 computes a maximum bipartite matching between row and column vertices.

Starting from unmatched rows, it follows alternating paths using

\[
\text{unmatched row→column edges}
\quad\text{and}\quad
\text{matched column→row edges}.
\]

A dual search starts from unmatched columns.

The resulting regions are reported as:

- under-region;
- over-region;
- well-region;
- overlap diagnostics;
- unmatched rows/columns;
- structural rank;
- exact algebraic rank.

This is deliberately called **DM-inspired**. R0.4 does not claim that this lightweight implementation is a complete canonical Dulmage-Mendelsohn decomposition in every graph-theoretic convention.

The important OAK invariant is retained:

\[
\boxed{
\operatorname{rank}_{\rm structural}(A)
\text{ can exceed }
\operatorname{rank}(A).
}
\]

For example

\[
\begin{pmatrix}1&1\\1&1\end{pmatrix}
\]

has full structural rank but exact rank one.

## 5. Min-fill elimination-width heuristic

R0.4 builds the row-intersection graph: two rows are adjacent when they share at least one nonzero column.

It then performs a greedy min-fill elimination. At each step it chooses the vertex that creates the fewest missing neighbor-neighbor edges.

The output includes:

\[
\boxed{
(w_{\rm elim},N_{\rm fill},\pi)
}
\]

where `w_elim` is the maximum active neighbor count under the chosen elimination order, `N_fill` is the number of fill edges introduced, and `π` is the order.

This is an **upper bound induced by one heuristic order**, not exact treewidth.

It is intended as a routing feature for later sparse determinant and Schur/separator compilers.

## 6. Multivariate proof-carrying Domain Ledger

R0.2 introduced an exact univariate cancellation ledger. R0.4 extends the idea to sparse multivariate polynomials over `Q`.

A polynomial is represented by exponent tuples, for example with variables `(x,y)`:

\[
x^2+xy+x+y.
\]

Given a proposed common factor `F`, R0.4 performs exact single-divisor multivariate polynomial division under a declared lexicographic monomial order.

Only if

\[
N=F\tilde N,
\qquad
D=F\tilde D
\]

hold with zero remainders does it emit the reduced rational expression.

The ledger still records

\[
\boxed{D(x_1,\ldots,x_m)\ne0}
\]

as the original guard and retains the cancelled factor explicitly.

Thus simplification means

\[
(N,D,F)
\rightarrow
(\tilde N,\tilde D,\text{ledger}),
\]

not merely `(N/F)/(D/F)`.

R0.4 does not yet claim a complete multivariate GCD engine or a full e-graph equality-saturation theorem prover.

## 7. Singular-safe rank-k update polynomial

For

\[
A(t)=A+tUV,
\qquad
U\in\mathbb F^{n\times r},
\quad
V\in\mathbb F^{r\times n},
\]

R0.4 computes exactly

\[
\boxed{
P(t)=\det(A+tUV)=\sum_{k=0}^{n}c_kt^k.
}
\]

No inverse of `A` is used.

Therefore the representation remains valid when

\[
\det A=0.
\]

Because

\[
\operatorname{rank}(UV)=q,
\]

the polynomial obeys

\[
\boxed{
\deg_t P\le q.
}
\]

R0.4 checks all coefficients above the exact update rank and validates the polynomial against independent direct determinants at multiple integer probes.

This generalizes the R0.3 global rank-one formula into a bounded rank-k polynomial surface without imposing an invertibility guard.

## 8. Characteristic-polynomial parameter derivatives

Consider a linear matrix path

\[
A(\theta)=A+\theta H.
\]

Define

\[
p(\lambda,\theta)=\det(\lambda I-A(\theta)).
\]

R0.3 already compiles the characteristic coefficients

\[
p=\lambda^n+c_1\lambda^{n-1}+\cdots+c_n.
\]

R0.4 reverse-differentiates **every characteristic coefficient output** with respect to all matrix entries and contracts the result with `H`:

\[
\boxed{
\dot c_k
=
\sum_{ij}
\frac{\partial c_k}{\partial a_{ij}}H_{ij}.
}
\]

An independent exact interpolation campaign on `A+tH` cross-checks each coefficient derivative.

The output is emitted in both descending and ROOTFLOW ascending conventions.

## 9. KRAMER × ROOTFLOW simple-mode velocity

For a supplied exact simple eigenvalue `λ` satisfying

\[
p(\lambda,0)=0,
\qquad
p_\lambda(\lambda,0)\ne0,
\]

implicit differentiation gives

\[
\boxed{
\dot\lambda
=-\frac{p_\theta}{p_\lambda}.
}
\]

This is exactly the root-flow differential law applied to the characteristic polynomial.

R0.4 computes `p_θ` from the exact characteristic-coefficient derivatives generated above.

If `numpy` and `omega_rootflow_t.core` are importable, it also performs an optional runtime cross-check against ROOTFLOW's `root_velocity()` implementation. The dependency is optional; absence of the numerical runtime does not invalidate the exact algebraic packet.

Two hard refusal states are tested:

1. the supplied value is not an exact eigenvalue;
2. `p_λ=0`, so the eigenvalue is multiple and simple-root coordinates are singular.

Thus

\[
\boxed{
\text{multiple mode}\Rightarrow\text{route to ROOTFLOW multiplicity strata, not simple velocity}.
}

## 10. Bounded equality-class rewrite planner

R0.4 begins the transition toward equality saturation without pretending to have a complete e-graph engine.

For a supplied square matrix it enumerates applicable exact candidates such as:

- Bareiss;
- Berkowitz circuit;
- subset circuit under its bounded dimension;
- diagonal/triangular product;
- disconnected support-block product;
- guarded Schur complements.

Each candidate carries:

\[
(\text{name},\text{value},\text{exact},\text{guard},\text{static cost},\text{provenance}).
\]

CVCD requires all eligible candidates to agree with the exact reference determinant.

Selection uses only a deterministic static cost. Refused candidates are retained in an M-minus list with their failed guards or budget reason.

Hence

\[
\boxed{
\text{enumerate equivalent forms}
\to
\text{verify}
\to
\text{remember refusals}
\to
\text{select bounded-cost form}.
}

This is a precursor to proof-carrying equality saturation, not yet the full system.

## 12. OAK stop conditions

Do not:

- promote CI timing ratios into deterministic algorithm rankings;
- call the DM-inspired partition a complete canonical DM decomposition;
- call min-fill elimination width exact treewidth;
- infer symbolic expression size from evaluated rational bit length;
- cancel a multivariate factor unless exact division succeeds in numerator and denominator;
- divide by `det(A)` in the rank-k update polynomial;
- apply simple eigenvalue velocity when `p_lambda=0`;
- select a rewrite whose guard is false;
- discard refused rewrites from M-minus evidence.
