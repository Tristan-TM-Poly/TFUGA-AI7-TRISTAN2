## Canonical fusion

This branch crystallizes the Radio-Canada/public-media work into one executable slice rather than another family of disconnected concepts:

`Ω-RADIO-CANADA-PUBLIC-KNOWLEDGE-OS-T + Ω-RADIO-CANADA-CIVIC-INTELLIGENCE-COMMONS-T + PEOS-T + TMDC-T + Ω-TRISTAN-MEDIA-MORPHOGENESIS-T + Ω-TRANSMISSIBLE-VERIFIED-IDEA-ECOLOGY-T + VKPR-T`.

`QUESTION → DISCOVER → TEST → CRYSTALLIZE → TRANSCODE → VERIFY → ROUTE → DIFFUSE → CRITIQUE → REGENERATE`.

Radio-Canada is treated as a possible high-reach public-media node, never as a controlled promotion channel. Editorial acceptance, rejection, contradiction, framing, and publication remain independent human decisions.

## Evidence levels

`HYPOTHESIS → FORMALIZATION → PROTOTYPE → MEASURED → REPLICATED → PROVEN`.

Reach is bounded by evidence maturity and correction capacity. A speculative object may be discussed as speculation, but the system must not silently promote it to proof, measured result or institutional fact.

## Public-media objective

Do **not** maximize direct exposure. Optimize a bounded public-value objective:

`VerifiedUnderstanding × IndependentReplication × CapabilityTransfer × Regeneration / (Hype + Distortion + CorrectionDebt + EditorialFriction)`.

This formula is an operational heuristic, not an established scientific law.
