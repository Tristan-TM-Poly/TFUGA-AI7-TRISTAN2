# Omega Generative Closure R0.1

This module is a bounded architectural measurement court for GO MAX / GO MIN.

It experiments with six canonical kernels: SENSE, MODEL, TRANSFORM, VERIFY, REMEMBER and MATERIALIZE.

The closure engine measures which derived operations are reachable from those kernels. Primitive-necessity analysis measures which derived operations are no longer reachable when one seed primitive is omitted. The MAX/MIN court separately tracks benefits such as verified value, evidence, reuse, reachability, regenerability and fertility, and costs such as execution cost, structural debt, proof debt, semantic debt, uncertainty and irreversibility.

The RepoCell analysis is diagnostic only. It reports KEEP, HOLD or COMPRESS as review classifications based on declared split score, capability uniqueness and overlap. These classifications do not perform repository mutations.

OAK boundary: these scores are architectural metrics. They are not scientific proof, permission, authority, or universal laws of intelligence.
