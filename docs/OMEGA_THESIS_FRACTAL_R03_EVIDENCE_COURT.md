# Ω Thesis Fractal Order-n R0.3 — Measured Evidence Court

R0.3 extends the R0.2 canonical registry court without adding another thesis ontology or GO MAX/MIN implementation.

```text
candidate thesis
→ matched benchmark
→ 12 explicit MetricMeasurements
→ EvidenceVectorReceipt
→ complete/provenance/baseline gate
→ existing MaxMinVector
→ sparse ZOOM
→ SURVIVE / PRUNE / HOLD_EVIDENCE
→ selected child
→ next measured court
→ T^(n+1)
```

Each normalized dimension carries the raw candidate value, matched baseline value, unit, direction, candidate provenance, baseline provenance, and normalization rule. Missing dimensions stay `HOLD_EVIDENCE` instead of being inferred.

Synthetic fixtures are `HOLD_EVIDENCE` by default. Tests may explicitly allow them only to exercise selection mechanics; the receipt still records no causal-superiority or external-truth claim.

`compile_evidence_registry_forest()` feeds only complete eligible receipts into the existing R0.2 registry court. `compile_measured_children()` applies the same evidence gate below any existing thesis node, so logical order n can grow without changing the meaning of n or promoting OAK maturity.

Permanent boundaries:

```text
measurement != truth
normalized score != natural law
matched baseline != causal proof
SURVIVE != scientific validation
PRUNE != refutation
HOLD_EVIDENCE != low scientific value
synthetic fixture != evidence
selection != global optimum
order n != epistemic quality
```

R0.3 implements the contract and deterministic court. It does not claim that the canonical seeds already possess complete real-world 12-dimensional receipts.

The next frontier is one narrow real benchmark path, preferably `OMEGA_TRANSFORM_T → FFWT`, followed by recursion only when the measured receipt survives the matched-baseline court.
