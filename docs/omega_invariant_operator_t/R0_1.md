# Ω-INVARIANT-OPERATOR-GENESIS-T R0.1

## Mission

Turn the current Zero-Heuristic discussion into a falsifiable operator-synthesis pilot.

```text
finite state representation
+ named invariants
+ explicit search-bias ledger
→ exact distance-shell synthesis
→ invariant-preserving operator witnesses
→ post-hoc classic-family recognition
→ baseline coverage court

```

The permanent wording is **ZERO-HIDDEN-HEURISTIC**, not literal zero heuristic. R0.1 exposes the representation, objective, grammar, enumeration order, tie-break and candidate budget rather than pretending they are absent.

## Why exact enumeration before SMT/SyGuS

An SMT or SyGuS engine still needs a representation and a synthesis grammar. R0.1 therefore starts with a small exact reference oracle whose completeness is easy to inspect. For a bounded finite set-state universe it exhausts complete symmetric-difference shells in increasing distance. If a valid non-identity target is found only after all smaller shells and the current shell are exhausted, minimality of that state delta is certified **within the declared finite model**.

If the candidate budget is hit first, the result is `HOLD`; the code does not promote a partial search to a minimality claim.

This exact engine is intended to become an oracle against which later SMT/SyGuS/CEGIS backends are differential-tested.

## TSP pilot

The TSP adapter declares only:

1. exactly `n` undirected edges;
2. endpoints belong to the node domain;
3. every vertex has degree two;
4. the graph is one connected component.

No `2-opt`, `3-opt`, swap, insertion, or other local-search name appears in the search operator library. The generic grammar is only `remove_element` / `add_element` over the declared finite edge universe.

For the canonical 5- and 6-node cycles in the focused court, the exact engine certifies a minimum non-identity symmetric difference of four edges and all first-shell witnesses have signature `(2 removed, 2 added)`. Only **after synthesis** does the adapter label that structural signature as the classic 2-edge-exchange / 2-opt family.

This supports a bounded statement:

> Under the declared finite undirected-cycle representation and invariants, the smallest non-identity invariant-preserving edge-set transition changes two old and two new edges.

It does **not** prove that 2-opt is the best TSP heuristic, that the representation is uniquely correct, or that the same result follows under every encoding.

## Baseline and apoptosis rule

R0.1 deliberately does not encode an unverified historical count of human operators. A caller may attach a real baseline registry with operator names and exchange signatures.

Apoptosis remains fail-closed:

```text
synthesis PASS
AND finite minimality certified
AND declared baseline signatures covered
AND semantic-equivalence evidence attached
AND benchmark noninferiority evidence attached
→ ELIGIBLE_FOR_REVIEW
```

Even then:

```text
automatic_delete = false
destructive_action_authorized = false
```

The old operator library must win or lose by differential evidence, not by architectural enthusiasm.

## Relation to existing Tristan kernels

This package is intentionally narrow.

- `omega_meta_science_t` remains the owner of representation arbitrage, invariant transport and discovery-dynamics concepts.
- `omega_generative_closure_t` remains the owner of GO MAX/MIN closure and primitive-necessity scoring.
- `omega_cheat_code_t` remains the owner of lifecycle ranking and proof-envelope planning.

R0.1 does not duplicate those ontologies. It contributes one missing executable primitive: **bounded invariant → operator witness synthesis**.

A later integration can compare exact-set, SAT/SMT, tensor and domain-specific encodings through the existing representation-arbitrage surface instead of inventing a second representation market.

## OAK boundaries

```text
minimal state delta != best optimization move
invariant preservation != objective improvement
bounded exhaustive search != scalable synthesis
explicit bias ledger != absence of inductive bias
post-hoc 2-opt recognition != independent mathematical invention
PASS receipt != empirical superiority
baseline coverage != semantic equivalence
green CI != theorem about general TSP complexity
```
