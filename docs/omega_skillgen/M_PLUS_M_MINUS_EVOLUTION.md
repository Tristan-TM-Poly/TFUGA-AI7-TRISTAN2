# Ω-SKILLGEN — Evidence-driven M+/M- evolution

The foundry now turns behavioral failures into explicit successor constraints rather than generic prompt rewrites.

## M- path

`failed eval → observed failure mode + evidence → cause hypothesis → targeted repair actions → adversarial regression case → successor candidate`

Supported deterministic repair signals include activation over-triggering, epistemic overclaim/proof confusion, approval/permission violations, missing baselines, and missing edge/adversarial coverage. Unknown failures are still preserved as generic must-pass regressions rather than discarded.

Cause hypotheses remain hypotheses. A generated repair is not considered successful until the original and newly generated regression cases are rerun.

## M+ path

Successful supplied evals become preservation contracts with their original evidence and numeric dimensions. They constrain future successors from silently losing demonstrated behavior. M+ does not fabricate new evidence: it only preserves the provenance of supplied successful evaluations.

## Recursive loop

`behavioral telemetry → M+/M- → repair candidate → Pareto arena → regression suite → behavioral rerun → promotion registry`

This closes the learning loop while keeping `STATIC_PASS != BEHAVIORAL_PASS` intact.
