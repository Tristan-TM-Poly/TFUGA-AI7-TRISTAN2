# Ω-REPO-GENESIS-T∞ R0.1

Ω-REPO-GENESIS-T∞ turns the repo-mycélium design into a bounded repository materialization compiler.

## Mother pipeline

```text
existing GitHub evidence
→ CapabilityGraph / RepoAtlas
→ gap + split score
→ RepoCell embryo
→ private materialization plan
→ repository creation boundary
→ repo.genome + capabilities + relations
→ OAK CI
→ EvidenceReceipt
```

R0.1 plans private repositories only. Public release is a different authority boundary.

## Materialization score

A logical RepoCell becomes a physical repository only when `split_score >= 0.72`. The score is a planning proxy, not proof that splitting is optimal.

## Anti-proliferation invariant

```text
Capability != PhysicalRepo
Idea != PhysicalRepo
VirtualRepo != PhysicalRepo
```

## Anti-fan-out invariant

```text
N consumers × N full-history crawls -> rate-limit failure
one authorized observation -> content-addressed snapshot -> many consumers
```

## OAK boundaries

- repository created != useful repository
- capability declared != capability validated
- same protocol != semantic equivalence
- generated README/CI != production readiness
- split score != theorem
- CI green != scientific truth
- private materialization != authorization to publish
- existing repository != permission to overwrite
- tool availability != authority
