# Ω-META-SCIENCE-FOUNDRY-T∞²

**Status:** D-MVP candidate / executable research architecture / OAK-bounded.

This package is the executable meta-science branch of the Tristan corpus. It is intentionally built as a sequence of bounded layers rather than as a claim of autonomous or universally superior science.

## Stack

### R0.1 — MetaScienceBench-T

Deterministic fixed-vs-adaptive experiment benchmark with Theory Genome, representation/CVCD seed, disagreement mining, OAK, Meta-OAK fault injection, M+/M- and verified gain per cost.

```bash
python -m omega_meta_science_t
```

### R0.2 — Ω-DISCOVERY-DYNAMICS-T

Adds Scientific IR / Discovery ABI, local epistemic-Jacobian surrogate, Residual Genome, finite Counterexample Compiler, Representation Arbitrage, heuristic unknown-unknown radar and Invariant Transport.

```bash
python -m omega_meta_science_t.discovery_cli
```

### R0.3 — Ω-DISCOVERY-GEOMETRY-ALGEBRA-T

Adds empirical Theory Quotient, anchor-preserving Adversarial Twins, evidence-dependence discounting, Epistemic Hessian, finite claim UNSAT core, proof-carrying transforms and OAK-first Scientific Superoptimizer.

```bash
python -m omega_meta_science_t.geometry_cli
```

### R0.4 — Ω-DISCOVERY-OPERATING-SYSTEM-T∞²

Turns the previous primitives into reusable scientific contracts: epistemic type checker, semantic Theory Diff, Scientific Build Graph + transitive invalidation, Proof-Carrying Claims, Verified Discovery Unit and Discovery ROI.

```bash
python -m omega_meta_science_t.operating_system_cli
```

See `DISCOVERY_OPERATING_SYSTEM_R0_4.md`.

## Unified progression

```text
R0.1 benchmark strategy
  -> R0.2 represent / residual / counterexample / transform
  -> R0.3 quotient / rival / evidence / geometry / superoptimize
  -> R0.4 type / diff / rebuild / certify / value
```

The emerging kernel is:

```text
observe -> compile -> represent -> discriminate -> falsify
-> diff -> rebuild -> certify -> compare -> promote rarely
```

## Mother invariant

```text
Generate broadly
-> discriminate cheaply
-> attack aggressively
-> type-check strictly
-> rebuild only what changed
-> promote only proof-carrying OAK-passed artifacts.
```

## OAK boundary

The stack does not claim general superiority over scientists or external AI-science systems, historical novelty of each primitive, universal causal inference, unrestricted theorem proving, semantic equivalence of arbitrary theories, a physical geometry of truth, true detection of unknown unknowns, autonomous scientific authority, safe unrestricted self-modification, researcher-equivalent productivity counts, or guaranteed company valuation/revenue.

Every stronger claim requires external benchmarks, equal budgets, calibration, independent evidence and domain-specific validation.
