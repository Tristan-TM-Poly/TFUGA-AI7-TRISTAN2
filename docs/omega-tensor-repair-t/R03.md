# Ω-TENSOR-REPAIR-T∞ R0.3

## Bases irréductibles, contractions et symétries de Young

R0.3 prolonge le produit tensoriel réparé au-delà du cas explicite `2D × 2D`.
La couche fournit des coordonnées exactes et reproductibles pour les tenseurs
carrés de dimension arbitraire, des contractions programmables et une première
infrastructure de symétries mixtes d'ordre supérieur.

## 1. Base irréductible réelle de rang 2

Pour tout entier `d ≥ 1`, le module construit une base orthonormale explicite de

\[
M_d(\mathbb R)
=\operatorname{Sym}^2_0(\mathbb R^d)
\oplus \mathbb RI
\oplus \Lambda^2(\mathbb R^d).
\]

Les dimensions sont

\[
\dim\operatorname{Sym}^2_0=\frac{d(d+1)}2-1,
\qquad
\dim\mathbb RI=1,
\qquad
\dim\Lambda^2=\frac{d(d-1)}2.
\]

La somme vaut exactement `d²`.

### Base diagonale sans trace

Pour `k = 1, …, d-1`, R0.3 utilise

\[
H_k=
\frac{1}{\sqrt{k(k+1)}}
\operatorname{diag}(\underbrace{1,\ldots,1}_{k},-k,0,\ldots,0).
\]

### Base symétrique hors diagonale

Pour `i < j`,

\[
S_{ij}=\frac{E_{ij}+E_{ji}}{\sqrt2}.
\]

### Canal isotrope

\[
I_0=\frac{I}{\sqrt d}.
\]

### Base antisymétrique

Pour `i < j`,

\[
A_{ij}=\frac{E_{ij}-E_{ji}}{\sqrt2}.
\]

L'ensemble `{H_k, S_ij, I_0, A_ij}` est orthonormal pour le produit de
Frobenius. L'analyse calcule les coordonnées, reconstruit le tenseur et conserve
un résidu explicite.

## 2. Contractions programmables

Une contraction est représentée par un plan ordonné de couples d'axes. Chaque
étape travaille sur le tenseur courant, produit un nouvel état et émet un reçu :

- forme d'entrée et de sortie;
- axes contractés;
- dimension sommée;
- norme avant et après;
- étiquette sémantique.

Exemple de double trace d'un tenseur d'ordre quatre :

```python
from omega_tensor_repair_t import ContractionPlan, ContractionStep

plan = ContractionPlan(
    (
        ContractionStep(0, 1, "first-trace"),
        ContractionStep(0, 1, "second-trace"),
    )
)
receipt = plan.apply(tensor)
scalar = receipt.output.scalar
```

Les numéros d'axes sont ceux du tenseur **après** les contractions précédentes.
Ce choix rend le plan compact, mais impose de documenter la séquence.

## 3. Diagrammes de Young

Une partition

\[
\lambda=(\lambda_1,\lambda_2,\ldots),
\qquad
\lambda_1\geq\lambda_2\geq\cdots>0
\]

représente une classe de symétrie du groupe symétrique.

R0.3 fournit :

- génération des partitions d'un ordre donné;
- diagramme et tableau canonique;
- longueurs et produit des crochets;
- nombre de tableaux standards;
- dimension de Schur par la formule crochet-contenu;
- symétrisation par lignes;
- antisymétrisation par colonnes;
- opérateur de Young déterministe.

Le nombre de tableaux standards est

\[
f^\lambda=\frac{n!}{\prod_{c\in\lambda}h(c)}.
\]

La dimension de la représentation polynomiale de `GL(d)` est

\[
\dim S_\lambda(\mathbb R^d)
=
\prod_{(i,j)\in\lambda}
\frac{d+j-i}{h(i,j)}.
\]

Le benchmark vérifie notamment l'identité

\[
\sum_{\lambda\vdash n}(f^\lambda)^2=n!
\]

pour les ordres finis testés.

## 4. Frontière OAK des opérateurs mixtes

Pour une seule ligne, l'opérateur de Young coïncide avec la symétrisation totale.
Pour une seule colonne, il coïncide avec l'antisymétrisation totale.

Pour les diagrammes mixtes, R0.3 applique une symétrisation normalisée par lignes
puis une antisymétrisation normalisée par colonnes. Cette opération impose la
symétrie recherchée, mais elle n'est pas présentée comme un projecteur orthogonal
universellement normalisé. Une normalisation par idempotents primitifs et une
séparation complète des multiplicités restent des travaux ultérieurs.
