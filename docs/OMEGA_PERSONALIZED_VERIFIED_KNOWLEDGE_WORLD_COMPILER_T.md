# Ω-PERSONALIZED-VERIFIED-KNOWLEDGE-WORLD-COMPILER-T∞Ω

Status: architecture / executable prototype. No claim of scientific proof, institutional deployment, or external affiliation.

## Doctrine

`Website != collection of pages`.

A specialized page is a projection of one shared evidence kernel:

`ENTITY/QUESTION -> INTENT -> KNOWLEDGE SUBGRAPH -> CAPABILITY MEMBRANE -> EPISTEMIC LENS -> KNOWLEDGE WORLD IR -> INTERACTION PROGRAM -> VIEW`.

The invariant is: **personalize the path to understanding, never the truth state**.

## Minimal ABI

A `KnowledgeWorldIR` carries:

- entity and declared context;
- audience profile and intent;
- world mode;
- stable knowledge-object IDs;
- canonical evidence status;
- operators and representations;
- capability membrane;
- personalization policy;
- residual field;
- reconstructible WorldReceipt.

## Initial profiles

The compiler registers generic profiles for general public, Radio-Canada/public media, journalist, researcher, teacher, student, founder/company, and institution. These are representation policies, not psychographic identities.

Only one persistent route is required. Profile and mode are compiled at runtime, avoiding one hard-coded page per person or organization.

## Constitution

- PersonalizeRepresentation != PersonalizeTruth.
- RelationshipState != EvidenceStatus.
- MediaCoverage != ScientificValidation.
- CanSee != CanExport != CanPublish.
- CanDo != MayDo.
- VisualAuthority <= EvidenceAuthority.
- HiddenPsychographicInference = 0.
- AutomaticPublication = 0.
- WorldPASS != GlobalPASS.

Sensitive or manipulative inference fields such as political orientation, health, religion, vulnerabilities, sexual orientation, ethnicity, or persuasion susceptibility are rejected from relationship context by the prototype kernel.

## First executable worlds

Three initial projections demonstrate reuse of the same object graph:

1. GENERAL / DISCOVER: clarity, public value, evidence and unknowns.
2. RADIO_CANADA / MEDIA: public relevance, evidence passports, visual demos, counterarguments, reproducibility, rights and correction capacity. The page explicitly states no affiliation or approval.
3. RESEARCHER / VERIFY: claims, methods, baselines, data/code, prior art, falsification and negative results.

Additional profiles reuse the same compiler rather than becoming separate persistent pages.

## WorldReceipt

Every generated world emits a receipt that explains:

- why it was generated;
- which profile and mode were used;
- which personalization inputs were rejected;
- whether publication or evidence mutation are authorized (both false in this public prototype);
- what residuals remain;
- that the world is reconstructible.

This enables a visible `Personalization Diff`: a visitor can compare the general view with a specialized view and see that representations/operators changed while evidence status remained invariant.

## OAK boundary

This implementation does not prove that personalized worlds improve understanding, retention, source retrieval, or collaboration. Those remain experimental claims. The next verification stage is a pre-registered user study comparing GENERAL vs specialized lenses while measuring understanding, task completion, source retrieval, accessibility, privacy risk and epistemic distortion.

- GO TRISTAN: generate candidate lenses, modes and interactions.
- GO TRISTAN2: learn which lenses improve verified task outcomes.
- GO TRISTAN²: generate/ablate competing interface grammars.
- GO PR MAX: materialize one smallest reusable world compiler.
- MULTI-MERGE-MAX: reuse the same Evidence Kernel across media, research, education and relationship views; prune any profile whose capability gain does not justify its debt.

Target objective:

`ΩWorld = VerifiedUnderstanding * TaskCapability * Reuse * Transparency * Regenerability / (PersistentComplexity + PrivacyRisk + EpistemicDistortion + MaintenanceDebt + CognitiveFriction)`.

Promotion requires measured `ΔΩWorld > 0`; architecture alone is not evidence of improvement.
