# Ω-AIT-GreatSages-Gauss-T∞ — R0.1

## Status

**Executable research architecture / historical reconstruction prototype.**

This release does **not** claim to reproduce the mind of Carl Friedrich Gauss, certify historical truth, or establish novelty for modern descendants. It compiles a source-aware historical seed into deterministic knowledge snapshots, replay cards, mirror prompts, dependency layers, an Ω-HISTOSCI-HG-T∞ graph, and snapshot-specific AIT-PANTHEON missions.

## Mother transformation

```text
historical corpus
  -> source-aware knowledge atoms
  -> chronological knowledge gate
  -> discovery dependency DAG
  -> target-withheld replay
  -> CVCD-style compressed invariant
  -> mirror compiler
  -> OAK attacks
  -> AIT-PANTHEON candidate cycle
  -> tested artifact / M+ / M-
```

The key constraint is:

```text
knowledge available at t != knowledge known after t
```

A GreatSage replay must therefore preserve a strict temporal boundary before claiming a genuine rediscovery-style experiment.

## Generic architecture

The runtime is deliberately sage-agnostic. `SageProfile` contains:

- source records;
- dated knowledge atoms;
- dated discoveries;
- explicit discovery prerequisites;
- candidate cognitive operators;
- epistemic labels.

Gauss is the first seed, not a hard-coded architecture.

## Gauss R0.1 seed

The initial executable chronology includes representative nodes for:

- early symmetry/compression motifs;
- empirical prime-density interest;
- 1796 regular 17-gon / cyclotomic representation shift;
- 1799 doctoral work on the fundamental theorem of algebra;
- 1801 *Disquisitiones Arithmeticae*;
- 1801 Ceres orbit reconstruction;
- 1809 *Theoria Motus* / published estimation workflow;
- 1827 curved surfaces / intrinsic curvature;
- 1830s magnetic measurement and terrestrial-magnetism program.

These are **seed nodes**, not an exhaustive Gauss corpus. Each one remains attached to source identifiers and an OAK warning that the bibliography requires later source-by-source expansion.

## Eight mirror families

Every discovery can compile to exactly eight explicit mirrors:

1. **Historical** — reconstruct using only knowledge available by the target year.
2. **Modern** — translate into modern theory and notation without novelty inflation.
3. **Inverse** — infer natural motivating problems from the result.
4. **Computational** — turn the invariant into code, tests and benchmarks.
5. **Domain** — search other fields for the same abstract problem DNA and state analogy limits.
6. **Tristan** — map through HGFM + CVCD + LOG/EXP + OAK + Bayes-Tristan and generate falsifiable descendants.
7. **OAK** — attack attribution, chronology, leakage, hidden assumptions and hype.
8. **Future** — explore modern counterfactual extensions, always labeled as counterfactual.

## Chronological replay

For a discovery at year `y`, R0.1 creates a replay gate at `y - 1` and withholds the target discovery. The replay card records:

- allowed knowledge atoms;
- blocked future atoms;
- prerequisites;
- prerequisite availability;
- whether the target was successfully withheld.

This is only a **leakage-control primitive**. A later release should support finer dates, publication delays, private notebooks, correspondence, language availability, library access and uncertainty over what Gauss actually knew at a given moment.

## Dependency DAG

The runtime topologically layers discovery dependencies and rejects:

- unknown prerequisite IDs;
- cycles.

A dependency edge means “used by this GreatSages replay model” and **not** “historically necessary and uniquely causal.”

## Ω-HISTOSCI-HG-T∞ bridge

`to_histoscience_graph()` converts the profile to the repository's existing directed historical hypergraph runtime:

- Gauss -> `PERSON` node;
- discoveries -> `EVENT` nodes;
- references -> `SOURCE` nodes;
- discovery/source -> `DOCUMENTED_BY` hyperedges;
- modeled dependencies -> `PRECURSOR` hyperedges.

The graph is deterministic and auditable with the existing Histoscience graph audit.

## AIT-PANTHEON bridge

`pantheon_cycle()` sends a year-gated GreatSages mission to the existing AIT-PANTHEON-OMEGA 16 roles × 16 modes engine. This means the historical layer immediately inherits:

- candidate generation;
- OAK attack heuristics;
- top/bottom selection;
- M+/M- compatible outputs;
- codex generation.

No new autonomous external-action permission is introduced.

## R0.2+ expansion path

The Gauss seed should grow along four independent axes:

### 1. Source depth

Primary works, mathematical diary, correspondence, notebooks, biographies, archive metadata and translations, each with provenance and licensing metadata.

### 2. Temporal depth

Year -> month/day -> document/event sequence -> `knowledge_diff(t1,t2)` -> historical uncertainty windows.

### 3. Discovery depth

Each discovery becomes a nested HGFM bubble:

```text
discovery
  -> problem
  -> observations
  -> representations
  -> failed paths
  -> invariant
  -> proof/algorithm
  -> publication state
  -> descendants
  -> mirrors
  -> OAK failures
```

### 4. GreatSages zoom-out compatibility

The generic profile already makes the next Tristan dezoom possible:

```text
Gauss
  -> many mathematical/scientific sages
  -> cross-sage influence hypergraph
  -> civilization-scale chronological knowledge graph
  -> GreatSages-Pantheon
  -> GreatSages-Evolution / cognitive-operator atlas
```

The future dezoom must not collapse cultures, fields or eras into a single ranking. It should preserve provenance, uncertainty, independent discovery, collective traditions, institutions, oral knowledge, anonymous contributors and contested attribution.

## R0.1 acceptance criteria

- chronology gate blocks future seed knowledge;
- target discovery is withheld during replay;
- dependency graph is acyclic and complete;
- exactly eight mirror kinds are emitted;
- future mirrors are counterfactual;
- Tristan mirrors are fertile hypotheses;
- Ω-HISTOSCI-HG graph audit is valid;
- AIT-PANTHEON can run on a gated snapshot;
- no historical impersonation or truth-certification claim is emitted.
