# Ω-AIT-GreatSages / Ω-GREATSAGES-TIME-MACHINE-T∞ — R0.2

## Status

**Executable research architecture / software-validated historical-reconstruction infrastructure.**

R0.2 does not reproduce, impersonate, or certify the mind of Carl Friedrich Gauss. It models auditable transformations between dated knowledge states and keeps historical evidence, reconstruction, cognitive-model inference, counterfactuals, and fertile hypotheses separate.

The mother transformation is now:

```text
historical corpus
  -> provenance tensor
  -> multi-axis temporal state
  -> layer-aware knowledge gate
  -> notation/instrument admissibility
  -> causal leakage firewall
  -> discovery genome
  -> operator program
  -> mirror algebra
  -> benchmark / anti-agent attack
  -> lineage receipt + epistemic debt
  -> OAK promotion or quarantine
```

The goal is not a biography chatbot. The target is a reusable machine for reconstructing and testing **knowledge transformations**.

## 1. Multi-axis time

R0.1 used a single year. R0.2 introduces:

```text
τ = (
  t_world,
  t_accessible,
  t_read,
  t_understood,
  t_discovered,
  t_written,
  t_published
)
```

The software rule is intentionally conservative: a missing private axis is `unknown`; it is not silently inferred from a publication date.

This makes it possible to distinguish:

- an idea existing in the world;
- an idea being accessible to a sage;
- an idea being privately understood;
- a discovery being written but unpublished;
- a result becoming public.

R0.2 currently seeds only a small Gauss subset. The model is general; the source depth is not yet exhaustive.

---

## 2. Five epistemic knowledge layers

R0.2 separates:

```text
WORLD
PUBLIC
PRIVATE
LATENT
COUNTERFACTUAL
```

Interpretation:

- `WORLD`: known somewhere in the modeled world;
- `PUBLIC`: publicly documented/available knowledge;
- `PRIVATE`: source-supported private knowledge or activity;
- `LATENT`: inferred recurring operator/invariant, never treated as direct history;
- `COUNTERFACTUAL`: modern-tool or alternate-history experiment.

Default historical contexts admit world/public/private layers and block latent/counterfactual layers.

The central OAK law remains:

```text
historical source
!= reconstruction
!= cognitive model
!= counterfactual
!= fertile hypothesis
```

## 3. Notation and instrument gates

R0.2 treats notation and instrumentation as enabling capabilities rather than decoration.

A historical context now includes:

```text
year
axis
allowed knowledge layers
available notation systems
available instruments
```

A knowledge atom can declare required notation or instruments. If the capability is not available by the modeled date, the atom is blocked.

Gauss R0.2 contains small seed examples for:

- late-18th-century algebraic symbolism;
- congruence notation;
- modern linear-algebra notation as a future/anachronistic capability;
- historical astronomical observations;
- geodetic triangulation;
- magnetic measurement apparatus;
- modern digital computation as future tooling.

These dates are architectural seeds, not an exhaustive history-of-notation database.

## 4. Causal Leakage Firewall

A true rediscovery benchmark must hide more than the target answer.

For a target discovery `D`, R0.2 computes its modeled descendants and masks:

```text
D
+ descendants(D)
+ every discovery after the gate year
```

The resulting pack exposes only discoveries visible before the gate.

This reduces hindsight leakage through a modern descendant or a later theorem that indirectly gives away the target.

The dependency DAG is still a **replay-model dependency graph**, not a claim that history had one unique causal path.

## 5. Knowledge Field

The current finite discovery universe can be partitioned at year `t` into:

```text
K_t = known
F_t = frontier whose modeled prerequisites are satisfied
U_t = remaining unknown in the finite seed
```

This is a finite software field, not a claim to know the true historical unknown-unknown space.

It provides a reusable API for future:

- frontier navigation;
- next-question generation;
- discovery tournaments;
- white-space search;
- curriculum compilation.

## 6. Discovery Potential / Barrier

R0.2 implements a bounded heuristic `DiscoveryPotential` with factors in `[0,1]`:

- proximity;
- representation access;
- data access;
- proof access;
- invariant access;
- instrument access;
- notation access;
- dependency access.

Accessibility uses a geometric mean so a missing enabling factor is not hidden by high scores elsewhere.

```text
barrier = 1 - accessibility
```

This is a benchmark heuristic, not a psychological or historical law.

## 15. Blind Historical Discovery Tournament

Contestants should receive a **sanitized contestant pack** that does not expose target content. Internal evaluator metadata may retain a hashed target identifier.

## 16. Meta-Sage Router

`route_operators()` and `meta_sage_plan()` provide a bounded router:

```text
problem tags
  -> ranked operator candidates
  -> adversarial counter-operators
  -> operator program
  -> stop conditions
  -> OAK requirements
```

Stop conditions include:

- no measurable gain over baseline;
- growing epistemic debt without evidence;
- counterexample invalidating the central invariant;
- chronology/provenance gate failure.

The Meta-Sage is therefore a controller, not an unbounded autonomous oracle.

## 18. Epistemic Debt

R0.2 records debt from:

- untested assumptions;
- weak dependencies;
- uncertain attribution;
- missing reproduction;
- unresolved counterexamples;
- provenance weakness.

The current weighted score is operational and revisable. It is not a universal epistemological constant.

Its purpose is to make unsupported expansion more expensive than source/test-backed promotion.

## 19. Proof of Provenance / Scientific Lineage Hash

Every generated artifact can receive a lineage receipt:

```text
artifact
<- sources
<- operators
<- transformations
<- tests
```

A deterministic SHA-256 lineage hash identifies the exact provenance recipe.

The hash proves deterministic identity of the serialized lineage payload. It does **not** prove truth, authorship, novelty, or legal IP status.

# M- negative memory introduced by R0.2

### M-GS-01 — chronology by publication date only

Failure: publication date is used as a proxy for access, understanding, discovery and writing.

Correction: preserve independent temporal axes and unknown values.

### M-GS-02 — target-only hiding

Failure: the target is hidden but descendants leak the answer.

Correction: causal descendant + future-date firewall.

### M-GS-03 — historical notation leakage

Failure: modern notation reveals the structure an agent is supposed to rediscover.

Correction: notation/instrument admissibility gates.

### M-GS-04 — personality mythology

Failure: inferred recurring operators are described as direct facts about a historical mind.

Correction: operators are source-linked computational abstractions with confidence and adversarial counter-operators.

### M-GS-05 — white space = novelty

Failure: an empty transformation/domain cell is called a discovery.

Correction: `WHITE_SPACE_CANDIDATE`; external literature audit is mandatory.

### M-GS-06 — hash = truth

Failure: deterministic lineage is confused with truth or ownership.

Correction: lineage hash proves only identity of the provenance recipe.
