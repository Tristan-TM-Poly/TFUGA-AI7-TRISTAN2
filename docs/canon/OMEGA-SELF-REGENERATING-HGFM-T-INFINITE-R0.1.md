## Core claim

The persistent object is not a giant knowledge graph. It is a minimal regenerative kernel containing verified proof-carrying hyperedges, M⁺/M⁻, provenance, residuals and morphogenesis rules.

## Operational loop

```text
World / observations
→ ResidualField
→ growth candidates
→ MorphogenesisPolicy
→ proof-carrying HGFM
→ OAK²
→ M⁺ / M⁻
→ conservative kernel compression
→ regeneration
→ RegenerationBench
```

## Epistemic status

This package is an architecture and executable research scaffold. It is not itself a scientific theory of nature. Analogies to mycelia, renormalization, immune systems or morphogenesis are computational metaphors unless separately formalized and empirically supported.
