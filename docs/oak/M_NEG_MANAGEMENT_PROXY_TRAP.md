# M− MANAGEMENT PROXY TRAP

Failure pattern: a convenient observable (hours, messages, meetings, office presence) is silently promoted into a latent trait such as commitment, leadership or value.

Guardrail:
1. name the direct outcome;
2. measure the proxy-outcome gap;
3. search for confounders;
4. prefer direct evidence when available;
5. prohibit hidden use in consequential personnel decisions;
6. revalidate across contexts before reuse.
