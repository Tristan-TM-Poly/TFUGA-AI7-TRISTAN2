# Best Learning Atlas — Ω-CODE-DOJO-T∞ R0.3

## Why the best learning is usually not another success

A repeated success can indicate competence, memorization, an easy distribution, or weak tests. R0.3 therefore gives priority to observations that reduce uncertainty or expose a mechanism.

## Priority 1 — Mutation survivors reveal weak judges

When a mutant survives, the immediate learning is not that the solver failed. The strongest supported claim is: **the current oracle set did not discriminate the mutation**.

Action:

1. reproduce the survivor;
2. minimize the counterexample;
3. add a regression test;
4. rerun all related strategies;
5. only then update mastery.

## Priority 2 — Recurrent minimal counterexamples

A single failure may be noise. A signature that recurs across tasks, languages, or campaigns becomes a high-value failure genome.

Repair value combines recurrence, mean information gain, mutation gap, and mean cost. The score is a routing heuristic, not a probability of truth.

## Priority 3 — Weak and uncertain skills

Low mastery alone can reflect too little evidence. High uncertainty alone can reflect a new skill. The curriculum prioritizes their combination:

```text
priority ~ weakness * (1 + uncertainty multiplier)
```

A skill should leave the repair queue only after independent exercises reduce uncertainty and improve the posterior.

## Priority 4 — Plateau classification

R0.3 separates:

- novelty plateau: no new addresses;
- information plateau: new work teaches little;
- efficiency plateau: information per cost collapses;
- mastery plateau: success rate stops moving;
- evidence plateau: future extension for stagnant proof strength.

More generated volume is not a universal fix.

## Priority 5 — Strategy crystallization

A strategy enters M+ only after high information efficiency, strong mutation score, independent distributions, an explicit applicability boundary, a falsifier, and a regression suite.

## Priority 6 — Transfer as a controlled hypothesis

Co-success between two skills suggests a bridge. It does not prove that one caused improvement in the other. The next experiment holds other axes constant and varies the proposed source skill.

## Benchmark findings

The R0.3 fixture history deliberately contains recurrent Unicode normalization failures, boundary and off-by-one failures, surviving mutation families, cross-language successes, and a final low-novelty, low-efficiency window.

The expected learning order is:

1. repair surviving Unicode and boundary mutants;
2. minimize recurrent counterexamples;
3. break the novelty plateau;
4. measure weak uncertain skills;
5. confirm transfer using paired controls;
6. crystallize only strategies that survive independent distributions.

## Negative memories

- M-1: pass rate is not mastery.
- M-2: coverage is not discrimination.
- M-3: correlation is not transfer causality.
- M-4: more generated tasks can deepen a plateau.
- M-5: a posterior mean without uncertainty invites overconfidence.
- M-6: a ledger proves integrity, not truth.
- M-7: benchmark optimization can replace real learning.
- M-8: cheap information can still be irrelevant.
- M-9: repeated errors must become tests or the memory is decorative.
- M-10: no learning claim may exceed its independent evidence.
