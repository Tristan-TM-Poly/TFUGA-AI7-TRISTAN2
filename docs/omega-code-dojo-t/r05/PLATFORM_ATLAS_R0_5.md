## Required distinctions

1. Metadata is not an unrestricted training corpus.
2. A public API is not permission to redistribute all content.
3. User-owned solutions and platform statements have different provenance.
4. Manual submission is the default.
5. A shadow fixture validates only the original synthetic fixture.
6. Review means unresolved policy or license questions must be settled before the action.
7. Blocked references stay in the evidence ledger so the system learns what not to do.
