# Ω-META-HMG-GENESIS-T∞ — R0 Specification

## Goal

Turn residuals into candidate capabilities while keeping generation, judgment, authority and reality distinct.

## Mother loop

`OBSERVE -> RESIDUALIZE -> GENERATE -> COUNTERGENERATE -> TRANSFORM -> VERIFY -> ABLATE -> DISTILL -> REGENERATE`

## Meta layers

1. Meta-generalization: common ArtifactGenome/Transformation semantics across artifacts.
2. Meta-generation: generators are represented by GeneratorGenome and can themselves be varied.
3. Meta-automation: workflows are generated just-in-time from residuals, goals, constraints and authority envelopes.
4. Meta-improvement: candidate improvements compete against frozen baselines and adversarial tests.
5. Meta-regeneration: persist minimal crystals/genomes/receipts, regenerate larger artifacts on demand.
6. Meta-crystallization: retain invariants and minimal generators rather than every historical expansion.
7. Meta-apoptosis: delete layers whose ablation shows no verified contribution and which remain regenerable.

## Constitutional gates

- Generated != Verified
- Generator != Judge
- Simulation != Reality
- Capability != Authority
- Complexity must pay rent
- A generator cannot rewrite the benchmark on which it is currently judged.
- A self-modification cannot self-authorize deployment.

## R0 falsification target

R0 is intentionally deterministic and toy-scale. Promotion requires stronger independent baselines, hidden/holdout cases, adversarial evidence attacks, uncertainty calibration, latency/compute measurement and external reproduction.
