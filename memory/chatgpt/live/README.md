# ChatMem live checkpoints

This directory stores **derived PUBLIC checkpoints** from explicitly authorized live ChatGPT context.

It is intentionally not a transcript archive.

Each checkpoint should preserve:
- capture epoch;
- exact source scope;
- source-turn hashes when message IDs are unavailable;
- typed HGFM nodes and hyperedges;
- provenance;
- OAK/privacy boundaries;
- pointers to related GitHub artifacts.

Raw/private ChatGPT text belongs outside this public repository by default.

## Origin

The first live capture epoch is `2026-08-10T22:42:00Z`, created after the explicit instruction to use the current conversation as the starting point.

Historical exports remain optional for backfilling material older than the origin checkpoint.
